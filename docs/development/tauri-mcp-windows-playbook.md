# Tauri MCP Windows Playbook

先明确要验的候选、使用新建测试档案，再选择窗口和系统观察手段。Beta 调试桥由 Debug 入口按 `EXOMIND_BETA_ENABLE_DEV_BRIDGE=1` 显式启用。实际监听地址与进程按本次实例核对。主窗和浮窗单独选择；业务写入范围与设备证据分别记录。

入口与候选见[开发快速上手](quickstart.md)和[版本状态](../AI-CONTEXT.md)。Android 系统验收另见[Android Windows 手册](tauri-android-windows-playbook.md)。
