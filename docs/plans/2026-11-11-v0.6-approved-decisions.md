# 外心 0.6 · r2 审批回读与执行决定

> 2026-11-11，Asia/Shanghai。来源：用户上传的 `exomind-review-v0.6-plan-r2-2026-11-11.md/json`，全局明确“可以据此推进，所有的问题我已回答”；本轮直接要求建立新目标并持续推进到可实测 demo。原始文件仅本地留存，不提交账号路径、批注ID及个人资料。
>
> 回读规则：自由回答和批注优先于选项标签；保存回答与未保存草稿分别归属。已读验收框只证明审阅，不证明工程通过。本文件记录用户裁决，实际进度见[执行计划](2026-11-11-v0.6-migration-ui-tauri-validation-plan.md)。

## 1. 最终可实测范围

用户希望时间块与总结等日常能力齐备后再试用，不以只会显示图标的静态页作为完成。新 demo 使用外心已有 React 组件、布局、字体、配色和交互，最终交付可直接打开的 HTML 与可启动的独立本地运行链路。合成离线模拟保留为对照，但不能替代真实持久化、两个独立 RT 的同步及真实模型验证。

Alpha 仍先关闭审计发现的隔离、裁剪和生命周期缺口，验证后封存编号产物与源码的开发分支检查点，再开始正式 Beta 核心。此处开发保存点不等于公开 Release 或替换日用 0.5。

## 2. 逐问题决定

| 来源 | 用户裁决 | 实施含义与边界 |
|---|---|---|
| Q01 | 时间块和总结齐了再实测；需要足够日常功能 | 验收 demo 包含真实记录/原件、同步、计时与反馈、回顾、设置、Agent 与导出。 |
| Q02 | 标签过滤模拟用途空间；档案机制保留为多用户隔离，常态一个档案 | 标签是浏览分类，不能充当权限隔离；数据、设备加入与 Agent 能力绑定档案，连接上不能共享其他用户所有上下文。保留可扩展多档案，首版不建设复杂云端账号服务。 |
| Q03 | 保留只增事件，更正通过追加，不做回改 | 记录原文不覆盖；稳定ID与同ID不同内容冲突。回收等操作可追加状态事实，不以修改历史原文实现。 |
| Q04 | 回收期，之后手动确认彻底清理；有价值的可捞回重新记录 | 本地回收/恢复和显式彻底清理分开，不自动因时间、摘要或转存删除原件。默认期长由可调整配置表达，不宣称用户已指定天数。 |
| Q05 | 最小完整邀请复制/分享；二维码后续扩展 | 配对一次携带身份/档案/可达地址；确认结果和连接状态分开。不要求手调多个token。草稿补充T3Code Peer/Link为研究线索，未因此增加首版扫码前置。 |
| Q06 | 前台即时，后台可靠补齐；最终一致即可 | 提供可恢复的追加事件合并/游标补齐；不承诺Android熄屏持续低延迟。T3Code同步线程是参考类比，不把CRDT/DSON名词当已选择的库。 |
| Q07 | 合并时间块轮转/切换事件，块由节点切出；保留空余块 | 新模型保存每个真实开始/暂停/恢复/切换/反馈事实；统一确定性时间线投影在一个时刻选出一个区间，保留并发来源和重叠原因，不能丢掉另一端事件。起初迭代使用可复核tie-break，不凭更大时间戳无痕覆盖。 |
| Q08 | 结束进入反馈，先与原版一致 | 保留行动结束与反馈阶段，沿用原反馈Dialog/快捷键；不借Beta先改为静默结束。 |
| Q09 | 按时间块选择分界，把之前的上下文压缩成总时间块或消息；提示系统后置 | 手动范围压缩是新派生对象，输出形态可选；原件/原文保留。范围选择和来源可追查，未选范围不自动压缩；“该压缩了”提示另线。 |
| Q10 | 叙述默认，建议按需，可配置 | 参考现有总结Agent叙述；不恢复任务/成长助手全量人格。 |
| Q11 | 外部Agent可指定追加，限当前档案；记录/总结类型严格区分 | API与新skill鉴别human、agent_note、summary等来源/标签；只读不修改，禁止跨档案和隐式清理，UI用既有特殊样式区别作者。 |
| Q12 | 失败可手动继续；基础限次重试和退避可做，配额交上游 | 不内置积分/能量/费用额度平台；总结任务状态、重试/取消可见，Magpie/提供商决定配额。自动重试次数是工程可调整默认，耗尽后待手动。 |
| Q13 | 只存播放列表文件本身，先最简模型 | 保存所选原件，不递归解析/抓取本地引用资源；远端缺引用明确说明。已保存回答意向空，但内容明确，草稿同意仅作一致性补充。 |
| Q14、Q23 | 按阈值/条件，小文件自动，大文件引用同步并按需P2P取回 | 记录/元数据先同步，原件可读状态单独确认；阈值配置可调。大文件保留源端原件，下载校验hash，源不在线/副本消失不假称可取回。 |
| Q15 | 原声先保存，按需转写；可配置自动ASR或边录边转 | 回放与派生文字独立；配置未启用/识别失败不会阻碍原件保存。真实浏览器录音/接口只在能力可用时启用。 |
| Q16 | Agent读/导出即可，选事件/时间块导出记录包 | 一向导出Markdown/manifest/已持有附件，缺件显式；不自动写Obsidian，不做双向知识库同步。相同能力提供Agent。 |
| Q17 | 记录为主，专注收起/展开浮层不影响记录；今日按日/周/月看块 | 原Chat持续挂载，专注浮层关闭不推列表几何、不丢草稿/滚动；复用旧Focus/feedback。日/周/月为轮转时间线投影，不恢复旧任务规划域。 |
| Q18 | 暖石延续，布局交互原版 | 直接引用现有token/CSS/组件，不另造衬线字体、墨青主题、分栏卡片系统替代产品。 |
| Q19 | 自己动作短反馈，保现布局 | 状态来自真实回执；后台事件聚合，不为每个网络chunk播放动画，不抢输入焦点。 |
| Q20 | 快速采集，沿用“唤起时快速聚焦”设置 | 既有偏好控制焦点；恢复原位和快速聚焦的语义不混用。热键冲突必须可见可重试。 |
| Q21 | 本机草稿自动存，显式提交；不做跨端草稿 | 草稿与正式记录回执分开，关闭隐藏/reload恢复；旧提交不能清掉新草稿。 |
| Q22 | 固定整组就绪后提交，可移除失败项；大文件可分条绕开 | 提交快照固定，添加/移除下一组不改变已提交集合。未成功不得清空；不强制所有文件和文字必须合并。Telegram作为后续交互参考。 |
| Q24 | 默认本机释放副本；其他端可选择跟进，快捷入口 | 释放副本不等于共享删除；其他设备跟进需显式选择，不自动擦除已有副本。回收、取回与缺件引用各有状态。 |
| Q25 | 保留派生与来源痕迹，类似引用被撤回 | 清理原件后总结/转写不自动牵连删除；来源显示已回收/已清理/可取回，不伪造成功打开。 |
| Q26 | 覆盖变化提示，按需更新，掌控感和自动化兼顾 | 初次自动总结可跑，迟到新输入标记可更新；旧结果仍按原快照可追查，新版本不抢阅读。 |
| Q27 | 文字自动，原件按需选择给模型 | 未选择媒体正文就显示未读/元数据，不冒充理解；真实原件外发与一般读取权限分别开。 |

## 3. UI 批注落实

三条界面批注一致要求直接复用外心已有资源。上一份vanilla模拟仅保留为功能示意，不是产品视觉基准。后续通过独立React入口和服务接缝实现，原Chat/NowInputRow、FocusTimerWidget/反馈Dialog、PageShell、主题token、设置registry直接使用；新的原件卡/日周月投影在这套布局内增量实现，并记录组件来源。UI新增仍待用户看到实际产物后评鉴，但不重复询问已经明确的暖石/原布局方向。

第四条同步批注明确最终一致性。实现应保留追加事实、稳定ID、身份/权限与恢复性补齐；CRDT/DSON是类比方向，不能拿名词代替两个真实RT的字节/回执测试。

## 4. 本轮工程委托的默认值

下列没有具体数值，允许在可逆实现中先做可调整工程默认，并在demo设置与交付证据中标明：自动原件同步大小阈值、重试次数/退避、回收期提示长度、日周月显示跨度。不能把这些数值写成用户个人偏好，也不能利用默认值自动删除、外发或共享其他档案。

暂不建设的系统：完整多用户登录服务器、隐式旧库导入、自动引用资源打包、自动知识库写入、主动压缩提示、无关自主life tick、内置配额平台。保留必要的档案和能力边界供后续扩展。
