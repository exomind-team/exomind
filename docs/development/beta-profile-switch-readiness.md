# Beta 档案切换的就绪状态

档案写入者就绪后，选择器必须能响应这一变化。持久化忙闲与写入者是否存在是两个
独立状态：仅改写 React ref 不会通知读取它的父组件，也不能依赖其他请求偶然引发重绘。

## 所有者与行为

- `DeviceWorkspace` 持有写入者，创建完成后向
  [ProfileSwitchGuardGate](../../src/beta/profile-switch-guard.ts) 绑定切换前的排空操作。
- 呈现层通过 `useSyncExternalStore` 订阅稳定的绑定快照，派生选择器、档案对话框和
  到点入口的就绪状态。读取快照不会执行排空或切换。
- 观察者退订不解除写入者；旧写入者释放时只能清除自己的绑定，不能清除替换者。
  关闭期间迟到的异步打开仍受原有 `cancelled` 检查约束。
- 用户实际切换时继续调用当前绑定，先保存并排空当前草稿；就绪通知不绕过持久化、
  权限或提交结果检查，也不改变计时、同步、浮窗的运行生命周期。

## 回归与候选边界

[gate 回归](../../tests/unit/beta/profile-switch-guard.test.ts)覆盖通知、替换者与退订；
[界面回归](../../tests/unit/beta/last-profile-ui.test.tsx)把持久化快照稳定保持为 pending，
验证写入者就绪本身足以更新选择器，避免用每次读取新建快照制造额外刷新。

2026-11-19 的受控旧／新 `BetaApp` 对照中，旧实现确实在选择器仍禁用的断言失败；
修复后同一用例通过。相邻档案、设备替换与意图恢复共 5 文件／33 项通过，完整工作区
TypeScript 检查通过，执行监督均确认自有进程清理。两份对照共享当前其他依赖，
这些结果只证明此源码切片，不代表完整历史版本或整包用户叙事。

本修复晚于冻结的 Beta18 payload `66124154`；Beta18 的构建与设备证据不覆盖它。
源码提交后仍需回读 CI，并在包含此修复的后续固定候选中验收真实档案切换。
