## 评论发布命令（每轮）

### 新增评论（推荐每轮一条）

```bash
npm run gh:comment -- --type pr --number <PR号> --file <本轮证据md文件路径>
```

### 追加到同一评论（可选）

```bash
npm run gh:comment -- --type pr --number <PR号> --comment #issuecomment-<评论ID> --mode append --file <本轮证据md文件路径>
```
