# ExoMind 记忆系统

> 每轮有价值的内容都要归档，形成可检索的知识库

## 目录结构

```
pm/memory/
├── long-term.md              # 长期记忆（宏观决策、路线图）
├── logs.md                   # 执行日志（每轮追加，时间线）
├── 知识点-XXX.md              # 经验库（主题分类，快速检索）
└── （其他专题记忆）
```

---

## logs.md 记录格式

每轮 Ralph Loop 完成后追加记录：

```markdown
## [日期] Ralph Loop 第 X 轮 - 任务名

### 执行摘要
- 任务：XXX
- 结果：成功/失败
- 主要变更：XXX

### 遇到的问题
| 问题 | 原因 | 解决方案 | 优化建议 |
|------|------|----------|----------|
| XXX | 为什么 | 怎么解决 | 下次怎么做 |

### 有价值发现
- 新方案/新模式
- 关键教训
```

---

## 知识点文件格式

按主题分类，便于快速检索：

```markdown
# 知识点：主题名

## 场景：什么问题
**问题**：描述
**方案**：解决思路
**记忆口诀**：便于记忆
```

## 使用原则

1. **及时归档**：每轮完成后立即记录，不要拖延
2. **结构化**：使用统一格式，便于检索
3. **提炼精华**：记录有价值的发现，不是流水账
4. **分类清晰**：知识点按主题分类，避免重复
