# ExoMind 集体经济与治理体系（公开摘要）

> 这是公开摘要版。完整版含具体分配参数和技术实现细节，对 Maintainer 开放。

> 本文档定义 ExoMind 的完整经济与治理设计：从愿景到收入、分配、劳动记录、组织治理、通用劳动交换协议。
>
> 这不只是一个软件的商业模式——它是一套通用的集体经济协议，ExoMind 是实现它的数字基座。

---

## 一、愿景与理论基础

### 1.1 定位

ExoMind 软件是数字基座。在它之上运行的，是一套通用的**劳动交换协议**——适用于任何行业（软件开发、翻译、科研、教育、甚至外卖）的集体经济协调机制。

```
ExoMind 软件（数字基座）
      ↑ 实现
通用劳动交换协议（经济协议）
      ↑ 支撑
集体所有制生产关系（社会关系）
      ↑ 服务
L4 主权认知生命（文明目标）
```

协议的价值可能超过软件本身——软件会迭代，但协议可以持续。

### 1.2 马克思论按劳分配与资本主义法权

出自《哥达纲领批判》（1875）：

社会主义阶段实行"各尽所能，按劳分配"。但马克思指出，按劳分配仍然是一种**资本主义法权**（bourgeois right）：

> "这种平等的权利，对不同的劳动来说是不平等的权利。
> 它默认地承认不同等的个人天赋......是天然的特权。
> 所以就它的内容来说，它像一切权利一样是一种不平等的权利。"

共产主义高级阶段实行"各尽所能，按需分配"——但需要生产力极大发展，当前做不到。

### 1.3 设计原则

1. **以按劳分配为基础**——承认劳动差异，激励贡献
2. **限制资本主义法权**——封顶、衰减，防止差距过大
3. **向按需分配靠拢**——基础工资保障基本生活
4. **防止积累变特权**——没有永久的荣誉、没有永久的权力
5. **集体协商决定一切参数**——比例、权重、封顶值全部由集体讨论
6. **去中心化的社会变革**——不靠国家权力，靠技术工具和经济激励

### 1.4 历史参照

| 历史实践 | 时期 | 核心机制 | 可借鉴 | 局限 |
|----------|------|----------|--------|------|
| 中国第一次过渡（私有→公有） | 1949-1956 | 公私合营，渐进转型 | 过渡轨道的渐进设计 | 自上而下，依赖国家力量 |
| 毛泽东时期八级工资制 | 1956-1978 | 工资差距 ≈1:3 | 封顶比例参考 | 待调研详细实践效果 |
| 中国第二次过渡（计划→市场） | 1978-1999 | 价格双轨制 | 双轨/三轨并存的可行性 | 方向是走向市场化 |
| 蒙德拉贡合作社（西班牙） | 1956-至今 | 工资差距 1:6，民主治理 | 长期运行的合作社范例 | 待调研详细分配制度 |

## 二、劳动记录：Labor Ledger（劳动证据链）

### 2.1 什么是 Labor Ledger

Labor Ledger 不是一个新系统，是 ExoMind 已有能力的延伸：

```
ExoMind TimeBlock（已有）：
  开发者用"时间块"功能跟踪工作
  → 开始/暂停/继续/结束，精确到分钟
  → 可关联 Issue、PR、分支

Labor Ledger（在 TimeBlock 之上加一层证据链）：
  → 把 TimeBlock 时长 + Git commit + PR/Review 事件串成一条记录
  → 每条记录包含前一条的哈希值 → 链式结构，篡改可被检测
  → 每条记录带 GPG 签名 → 无法伪造身份
  → 多节点同步 → 单点无法篡改

简单说：TimeBlock 记录"你干了多久"
        Labor Ledger 让记录变成"不可篡改、不可否认的分配依据"
```

### 2.2 记录主体

**当前阶段**：只记录人的劳动。

**未来扩展**：留存 Agent 劳动记录的空间。ExoMind 的 CognitiveLifeAgent 设计（SOUL.md + Energy + CognitionEngine）正在探索 Agent 的主体性边界。当 Agent 满足认知生命的判据时，它的劳动也应该被记录和认可。

### 2.3 劳动类型

| 类型 | 说明 |
|------|------|
| code（代码） | 代码贡献 |
| review（评审） | PR 评审，需要深度理解 |
| ops（运维） | 保持系统运转 |
| design（设计） | 创造性劳动 |
| docs（文档） | 降低社区门槛 |
| discussion（讨论） | 集体协作必要环节 |
| invisible（不可见劳动） | 社区维护、冲突调解、新人引导 |

类型权重由全体成员协商，每季度可调整。调整记录写入 Labor Ledger 治理链。

## 三、三层劳动模型

### 3.1 每日劳动分层

```
第一层：必要劳动（0-4 小时/天）
  → 基础工资 + 劳动报酬
  → 含集体讨论时间（每日分享 30 分钟）
  → 集体对你的承诺：你履行了义务，集体保障你

第二层：额外劳动（4-8 小时/天）
  → 劳动报酬（受月度封顶限制）
  → 自愿多干，分配上有体现，但不会无限增长

第三层：义务劳动（8 小时以上/天）
  → 记录在 Labor Ledger，但不作为分配依据
  → 奖励：流动荣誉称号
  → 原则：为集体服务，不为物质奖励
```

### 3.2 基础工资门槛

月度门槛：60 小时/月（约 4小时/天 x 15-20天）。数据来源为 Labor Ledger。

三种状态：
- 达标（>=60h/月）：基础工资 + 劳动报酬
- 不达标（>0h）：只有劳动报酬（等同 Reviewer）
- 不活跃（0h）：无收入，连续 2 个月暂停 Maintainer 权限

### 3.3 集体工作节奏

集体时间是劳动的一部分，计入 Labor Ledger（discussion 类型）：

- **每日**：工作结束前 30 分钟集体分享。不是汇报，是平等交流。
- **每周**：1 小时集体会议。成果共享、方向讨论、分工调整、互相帮助。
- **每月**：1-2 小时集体回顾。Labor Ledger 透明审视、分配计算、参数调整。

这不是"管理"，是**集体生活**——没有管理者和被管理者，只有平等协作的劳动者。

### 3.4 流动荣誉

义务劳动以流动荣誉认可，不折现为金钱。月度评定，不达标自动取消，没有永久称号——防止荣誉变特权。历史记录保留，但不授予当前特权。

### 3.5 防止自我剥削

8 小时以上不折现，防止"自我剥削"和集体版 996。多干不多拿钱，想多干的人是出于信念，集体给的是认可，不是金钱。

## 四、收入来源

### 4.1 永久免费部分

- ExoMind 软件本身（本地运行，任何人任何团队大小）
- 开源代码和文档
- <=3 人团队的全部功能（鼓励初创集体）

### 4.2 收入渠道

| 渠道 | 来源 | 定价 |
|------|------|------|
| 云端资源 | 算力/存储/网络/LLM API | 按量付费（成本+劳动+积累） |
| 团队高级功能 | 管理面板/审计/Labor Ledger 仪表盘 | 按功能付费 |
| 标准商业授权 | 资本主义企业 | 标准价 |
| 透明商业授权 | 公开账本的企业 | 优惠价 |
| 教育优惠 | 学生/高校/教育机构 | 限额优惠（需认证） |
| 劳动交换 | 劳动者所有组织 | 以劳动换使用权 |
| 捐赠/赞助 | 自愿 | 自愿金额 |

### 4.3 定价公式

```
单位价格 = (基础设施成本 + 劳动报酬 + 集体积累) / 个人付费用户数

→ 用户越多 → 人均成本越低 → 定价越低
→ 集体积累 = 马克思说的"扩大再生产基金"，不是"利润"
→ 月度可浮动，公开成本结构（FINANCES.md）
```

### 4.4 教育优惠

学生和教育机构可申请限额优惠，需通过身份认证。具体折扣和名额由集体根据当期收入状况协商决定。认证有效期：学生 1 年（可续期）/ 机构 2 年。

## 五、三轨交换制度

### 5.1 按生产关系分轨，不按团队大小分

同样 3 个人的团队，生产关系可能完全不同。判断标准不是人数，是组织性质。

### 5.2 组织评分体系

四维度评分（每维 1-5 分，满分 20）：

| 维度 | 评估内容 |
|------|----------|
| **A. 利润分配** | 利润中多少比例分配给全体劳动者？ |
| **B. 决策权** | 管理者由谁选出？劳动者有没有真正的投票权？ |
| **C. 工资差距** | 最高薪和最低薪之间的比例 |
| **D. 治理透明** | 财务是否对全体劳动者公开？决策过程是否可追溯？ |

### 5.3 三轨判定

| 轨道 | 总分 | 适用对象 | 交换方式 |
|------|------|----------|----------|
| 资本主义轨道 | 4-8 分 | 普通商业公司 | 标准定价，货币交换 |
| 过渡轨道 | 9-15 分 | 渐进改革的组织 | 渐进优惠，每提高 1 分价格降 5-10% |
| 社会主义轨道 | 16-20 分 | 劳动者合作社 | 劳动交换 / 预收益期免费 / 最低价 |

### 5.4 过渡轨道的引导机制

每提高 1 分，价格降低 5-10%。ExoMind 用经济激励一步步引导生产关系变革——不是强制，是"你改变了，我就便宜给你"。

### 5.5 劳动者所有组织特殊待遇

- 预收益期（还没跑起来）：免费使用，帮助新集体存活
- 有收益后：劳动交换或低价货币
- 不是"免费"，是另一种交换——用劳动（代码/翻译/文档/测试）换使用权

## 六、通用劳动交换协议

### 6.1 这是什么

```
历史上三种经济协调方式：

方式一：市场（资本主义）
  劳动 → 商品 → 货币 → 商品 → 劳动
  → 问题：劳动被异化为商品，剩余价值被资本占有

方式二：计划（传统社会主义）
  中央计划 → 分配任务 → 分配消费品
  → 问题：信息不对称，官僚化

方式三：劳动交换协议（ExoMind 探索的）
  劳动 → Labor Ledger（可验证记录）→ 集体间直接交换
  → 没有货币中介（或货币只是辅助）
  → 没有中央计划（集体自主协商）
  → 基于真实、可量化、可验证的劳动记录
  → 去中心化：不靠国家，靠集体间协议
```

这是马克思在《哥达纲领批判》中设想的"劳动券"的数字化实现。

### 6.2 集体间交换示例

ExoMind 集体与翻译合作社之间：翻译合作社提供 200 小时翻译劳动，ExoMind 提供 6 个月云端服务（等价运维+算力劳动）。交换基础不是市场定价或计划分配，是**劳动时间等价交换**。两个集体的 Labor Ledger 互相签名确认，交换记录写入双方的哈希链，不可篡改，永久可追溯。

### 6.3 协议的通用性

这个协议不局限于软件行业。任何可以记录劳动时间和产出的行业都可以接入：软件开发、科研、教育、翻译、外卖、制造。ExoMind 软件是数字基座，协议是通用标准。

### 6.4 与历史的关系

- 中国第一次过渡（1949-1956）：可借鉴过渡轨道的渐进设计，区别是 ExoMind 不靠国家力量，靠经济激励
- 中国第二次过渡（1978-1999）：可借鉴双轨/三轨并存的可行性，区别是方向相反——从市场向劳动交换过渡
- 马克思的劳动券设想：Labor Ledger = 数字化劳动券，哈希链 + GPG 签名 = 不可篡改、不可伪造
- 去中心化的社会变革：每个采用 ExoMind 的集体就是变革的一个节点，集体间通过劳动交换协议互联

## 七、分配流程

### 7.1 第一步：集体留存

个人分配前，先扣除集体需要（马克思《哥达纲领批判》的扣除原则）：

- 基础设施成本（实报实销）
- 发展基金（扩大再生产）
- 风险储备（应对突发）
- 互助基金（帮助困难成员）

### 7.2 第二步：个人分配

- **基础工资**：所有达标 Maintainer 平均分，方向是按需分配
- **劳动报酬**：按 Labor Ledger 加权贡献度，封顶限制，超出部分回流互助基金

### 7.3 封顶与衰减

- **收入封顶**：个人总收入不超过基础工资的 N 倍
- **贡献度衰减**：半衰期 12 个月，只计算近期活跃贡献，防止历史贡献变历史特权
- **荣誉流动**：月度评定，不达标自动取消，没有永久称号

## 八、组织治理

### 8.1 贡献者等级（信任升级）

```
L0 Community Member → L1 Contributor → L2 Reviewer → L3 Maintainer

评估维度：
  L0→L1: 贡献质量（提交被合并的 PR）
  L1→L2: 能力 + 持续性
  L2→L3: 能力 + 意愿 + 理想一致性

技术是门槛，理想是钥匙。
```

### 8.2 决策机制

| 类型 | 方式 | 例子 |
|------|------|------|
| 日常技术 | 任一 Reviewer 批准 | PR 合并 |
| 架构变更 | Maintainer 多数同意 | 新模块 |
| 方向调整 | 全体 Maintainer 讨论+多数 | 路线图 |
| 所有制/许可证变更 | 全体 Maintainer 一致 + 30天公示 | LICENSE 修改 |
| 人事 | 全体 Maintainer 一致 | 新增/撤销 Maintainer |

### 8.3 防止异化

1. **防止资本化**：任何人不得将集体资源转为个人资本
2. **防止官僚化**：Maintainer 是服务者，权限可撤销，无终身制
3. **防止商品化**：用户认知数据不是商品
4. **防止垄断化**：代码永远公开，任何人可 Fork
5. **防止特权积累**：贡献度衰减 + 荣誉流动 + 无永久称号

### 8.4 透明度承诺

- 所有收入和支出公开（FINANCES.md）
- 所有决策过程可追溯（Git 记录）
- 所有劳动记录公开（Labor Ledger）
- 参数变更需公示期
