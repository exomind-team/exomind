# ExoMind 官网首页组件与展示方式样本库

> 日期：2026-04-09  
> 范围：仅统计本轮 12 个参考官网的 **首页** 中出现的组件家族、展示方式与可见交互骨架。  
> 目标：为 ExoMind 官网改版积累“页面展示原材料”和“平面设计样本”，形成一份 **去重、可分类、可溯源** 的首页组件目录。

---

## 1. 使用说明

### 1.1 这份样本库解决什么问题

上一份扩展交叉分析稿主要回答：

- 首页应该怎么讲
- CTA 应该怎么分层
- 下载入口应该怎么设计

这份样本库则专门回答：

- 这些官网首页都在用哪些可见组件
- 这些组件是怎么展示的
- 用户看到它们时，是怎样被引导交互的
- 哪些展示方式值得当成 ExoMind 的页面原材料

### 1.2 去重规则

为避免重复，这里按“组件家族”而不是“像素级变体”归类。

也就是说：

- 如果多个站点都用了“首屏主 CTA + 次 CTA”，只记为一个家族
- 如果它们的视觉风格不同，会写在“展示方式”里
- 同一站点重复出现的同类组件，不重复计数

### 1.3 如何理解“可溯源”

每一个组件家族都带有来源站点的 Markdown 链接。  
这些链接都指向对应官网首页，方便后续回看原始样本。

## 4.3 CTA 组件

| ID | 组件/方案 | 展示方式 | 交互方式 | ExoMind 可用位置 | 来源样本 |
|---|---|---|---|---|---|
| `C01` | 单一强主 CTA | 首屏只强调一个动作，其他动作弱化 | 点击即跳转/下载 | 极强单点转化首页 | [LazyTyper](https://lazytyper.com/zh) |
| `C02` | 主次 CTA 并排 | 一个高对比主按钮 + 一个弱化次按钮或描边按钮 | 主按钮负责转化，次按钮负责解释/演示/文档 | Hero、收尾 CTA | [KnoxChat](https://knox.chat/)、[LocalSend](https://localsend.org/zh-CN)、[Zed](https://zed.dev/)、[Calimero](https://calimero.network/)、[FlClash](https://flclash.dev/)、[XMind](https://xmind.cn/)、[uTools](https://www.u-tools.cn/index.html) |
| `C03` | 主按钮 + 文本次链接 | 主动作是按钮，次动作不做成按钮，只做文本链接 | 降低次动作存在感 | Hero 主区 | [Obsidian](https://obsidian.md/) |
| `C04` | 平台感知 / 分体 CTA | 主按钮默认显示当前平台，旁边附一个 `More platforms` 或下拉切换 | 平台识别、下拉选择、环境感知 | 下载型首页 Hero | [Obsidian](https://obsidian.md/)、[LazyTyper](https://lazytyper.com/zh) |
| `C05` | 命令/快捷键强化 CTA | 在按钮里附带 `npx ...`、快捷键字母或开发者语义标识 | 点击仍是普通跳转，但展示层强化开发者语境 | 面向开发者的 Hero CTA | [VibeKanban](https://www.vibekanban.com/)、[Zed](https://zed.dev/) |
| `C06` | 双下载按钮 | 并排放两个同层级下载按钮，例如高速下载 / 本地下载 | 两个按钮都直接下载，但导向不同线路 | 国内下载型官网 | [xTerminal](https://www.xterminal.cn/) |

## 5. 最值得优先沉淀的 ExoMind 首页原材料

如果只考虑“下一版官网最值得立即吸收的原材料”，优先级建议如下：

### 第一优先级：直接影响首屏转化

- `H02` 一句话价值标题
- `C02` 主次 CTA 并排
- `C04` 平台感知 CTA
- `P01` / `P02` / `P03` 真实产品证明
- `D01` 平台卡片下载入口

### 第二优先级：建立信任与成熟感

- `T01` GitHub / 数字徽章
- `T02` Logo 墙 / 背书条
- `T05` 本地优先 / 隐私承诺卡
- `I02` FAQ 折叠问答

### 第三优先级：为后续页面系统积累版式资产

- `F01` 图标功能卡网格
- `F02` 能力层 / 支柱卡
- `F03` 场景展示
- `F04` Tabs / 分段切换展示
- `V05` 架构/线框插图

## 6. 给 ExoMind 的具体使用建议

### 可以直接组合的一套首页骨架

1. 用 `H02 + H04` 重写 ExoMind 的 Hero 文案
2. 用 `C02` 做首屏主次动作
3. 用 `C04 + D01` 改造当前 `SmartDownloadLink`
4. 用 `P01 / P02 / P03` 之一把真实界面提前到首屏
5. 用 `F02` 重组现有 capability layers
6. 用 `T05` 把本地优先和边界承诺说得更像“可信承诺”，而不是抽象理念
7. 用 `I02` 在下载前收口用户顾虑

### 最不建议直接照搬的部分

- `H03` 宣言型标题作为首屏主轴
- `V02` 的重霓虹科技感直接套到 ExoMind
- `uTools` / `XMind` 那种首页超大信息容量
- `Knox` 那种几乎等于后台壳层的首页结构

## 7. 结论

这份样本库的作用，不是告诉 ExoMind 去复制某个站点，  
而是把 12 个首页里的“可复用组件家族”拆出来，方便后续做页面设计时直接组装。

如果要把结论压缩成一句话：

**ExoMind 下一版官网最该沉淀的，不只是文案方向，而是一套可以反复重组的首页组件资产。**

这些资产现在已经可以明确分成：

- Hero 资产
- CTA / 下载资产
- 产品证明资产
- 功能展示资产
- 信任与 FAQ 资产
- 视觉基底资产

接下来无论是做 wireframe、视觉稿还是 Astro 实现，都可以直接从这份目录里挑选和组合。
