执行要求：

1. 对每条 reviewer 或人类评论，先引用原文关键句。
2. 遵循“先回复再决策”：

   - 再决定改代码、解释原因，还是明确无需改码

4. 若这轮无需改代码，也要发结构化回复，不要只说“收到”。

完成条件：
