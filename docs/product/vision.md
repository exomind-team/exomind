# ExoMind Vision

> 产品层宣言。源码工作目录 Agent 的执行合同见项目根目录 [AGENTS.md](../../AGENTS.md)。

## 定位

ExoMind（外心）是一个**个人/集体的生命成长助手**，也是一个**认知生命科学原型**。

它要解决的不是单点软件功能，而是两个更根本的问题：

1. 人如何主动掌控自己的生命过程。
2. 生命 / 思维机器如何在计算机上持续运行、持续决策、持续承担后果。

## 使命

ExoMind 的近期使命是：帮助用户把任务、时间、事件、承诺和反馈组织成一个可持续推进的生命过程，而不是一堆彼此孤立的软件功能。

## 长期方向

ExoMind 的长期方向不是“更聪明的助手”而已，而是探索一种具备以下特征的认知系统：

- 持续运行，而不是只在请求到来时短暂响应
- 有边界、有资源约束、有真实环境裁决
- 能留下痕迹、承担后果，而不是每轮对话都视为可完全回滚
- 能在个体成长、协作治理和长期文明积累之间建立连续性

## 边界

1. 本文档定义的是产品想服务什么、长期想成为什么。
2. 它不定义源码工作目录里的 Agent 应该如何执行开发工作；那由 [AGENTS.md](../../AGENTS.md) 决定。
3. 用户侧 runtime agent 的人格与 prompt 契约，见 [docs/agents/runtime-agent-contract.md](../agents/runtime-agent-contract.md)。
