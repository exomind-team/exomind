### 有价值发现

1. **双轨制 Git 工作流**
   - Draft PR：创建分支即提，AI 自转，人类可见进度
   - 正式 PR：功能完成，请求人类审查
   - 人工合并：只有人类能点 merge，掌握最终决策权

2. **架构文档分层方案**
   ```
   docs/
   ├── architecture/     # 系统蓝图（整体怎么搭）
   │   ├── 7-LAYER.md
   │   └── DECISIONS/    # 架构决策记录 ADR
   └── specs/            # 施工图纸（模块怎么做）
       └── SPEC-XXX.md
   ```

3. **知识点管理**：需要单独维护可检索的经验库
