# ExoMind MVP - 外心最小验证版

> 记录生命中的每一个事件

## 简介

ExoMind MVP 是一个轻量级的事件日志与时间块管理工具，采用纯 TypeScript 实现，无需任何外部依赖。它是 ExoMind 系统的最小验证版本，专注于验证核心逻辑「记录事件与时间块」。

## 核心特性

- **事件日志系统**：记录每一个瞬时事件，支持内容与标签
- **时间块管理**：追踪专注时段，支持开始/结束标记
- **REPL 交互模式**：简单直观的命令行交互
- **数据持久化**：自动保存至本地 JSON 文件
- **智能提醒**：超过4小时未结束的时间块自动标记异常

## 架构设计

### 核心数据结构

```
┌─────────────────────────────────────────────────────────────────┐
│                      ExoMind MVP 架构                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ┌──────────────────┐                                          │
│   │   ExoMindApp     │  ← 顶层应用层                             │
│   │   (主控制器)      │     协调日志系统、时间块连缀、展示呈现      │
│   └────────┬─────────┘                                          │
│            │                                                    │
│   ┌────────▼─────────┐                                          │
│   │   ExoMindLogs   │  ← 数据管理层                             │
│   │   (日志系统)     │     事件集合 + 时间块集合                  │
│   └────────┬─────────┘                                          │
│            │                                                    │
│   ┌────────▼─────────┐                                          │
│   │ Event & TimeBlock│  ← 基础数据类型层                         │
│   └──────────────────┘                                          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 类型系统 (types.ts)

| 类型 | 说明 |
|------|------|
| `Event` | 事件：唯一ID + 时间戳 + 内容 + 标签 + 元数据 |
| `TimeBlock` | 时间块：两个事件（开始/结束）组成的连续时段 |
| `PlannedTimeBlock` | 计划中时间块：只有开始事件，用于追踪活跃块 |
| `ExoMindLogs` | 日志系统：事件与时间块的集合管理 |
| `ExoMindApp` | 应用程序：整合日志、时间块连缀、UI展示 |

### 设计原则

1. **可序列化性**：所有数据均可转换为 JSON，便于存储与传输
2. **无状态设计**：事件只读不可修改，保证数据完整性
3. **扁平化存储**：时间块只存储事件的 UUID 引用，而非嵌套对象
4. **接口分离**：类型定义与实现分离，支持多种后端实现

## 使用方法

### 启动命令

```bash
bun main.ts
```

### 交互命令

| 输入 | 动作 |
|------|------|
| `开始xxx` | 开始一个新的时间块，名称为 xxx |
| `结束` | 结束当前活跃的时间块 |
| 普通文本 | 记录为普通事件 |
| `exit`/`quit`/`q` | 保存数据并退出 |
| `RESET` | 重置所有数据（需确认） |

### REPL 界面

**启动时展示：**
- 欢迎语
- 已加载的事件数与时间块数
- 当前活跃时间块状态
- 最近10个时间块详情

**提示符：**
- 有活跃块：`[块名] >`
- 无活跃块：`> `

## 开发说明

### 技术栈

- **语言**：TypeScript 5.x
- **运行时**：Node.js
- **依赖**：无外部依赖
- **工具**：bun / ts-node

### 代码结构

```
mvp/
├── main.ts          # 主程序入口与实现
├── types.ts         # 类型定义（接口 + 类型）
├── README.md        # 本文档
├── .gitignore       # Git 忽略规则
└── data/            # 数据存储目录
    └── exomind.json # 持久化数据文件
```

### 模块划分

| 文件 | 职责 |
|------|------|
| `main.ts` | ANSI 颜色、工具函数、Event/TimeBlock 实现、ExoMindLogsImpl、ExoMindAppImpl、CLI 交互 |
| `types.ts` | JSONValue/JSONObject/JSONArray 基础类型、Event/TimeBlock/ExoMindLogs/ExoMindApp 接口定义 |
