# Beta 用户需求、界面原则与任务叙事

本清单汇总本轮交接与用户在 Beta09–14 迭代中明确提出的要求。产品范围以 Beta 计划为准，状态以执行记录为准；本文件不宣称所有能力已经实现。2026-11-18 用户要求 TDD 锁死显示与业务运行的边界；2026-11-19 进一步明确统一主题控件、禁止原生滚动条，以及反馈输入不得造成无信息意义的按钮抖动。

## 不可退让的边界

1. **显示态不拥有业务生命期。** 隐藏、折叠、切页、最小化只是呈现选择，不得停止计时、同步、传输、草稿持久化或其他合法控制面的状态更新。视图可以停止无用绘制；业务服务由其数据/运行所有者启停。退出、关闭档案等领域动作仍遵循原有合同，不能把“永不停止”扩大成无生命周期资源。
2. **核心可靠性优先。** 先完成同步、多端时间块、文件传输的复现与最小修复，再做关键 P1，最后收尾 Beta。文字到达、时间块历史/投影可解释、原件字节到达是三个验收结果。
3. **本地优先与用户事实。** 已有记录、草稿和附件不被诊断、换版本或重试覆盖；不往真实档案写开发报告。设备授权与外部 Agent grant 分开，最小权限、可撤销；secret 不进入界面报告、测试日志或模型请求。
4. **能耗与观测成本受重视。** 平板 USB 充电仍掉电是实测线索，不是归因结论。不能用动画替代运行状态；不能让性能面板自身成为高频负载。APK/EXE 文件大小、安装占用、运行时内存与能源分别测量。
5. **测试不能代替人的观看与使用。** 构建通过不等于现场通过，控件存在不等于顺手；保留同一候选/设备/输入/场景证据与未验证项。Agent 评审不能代替人类审美审批。
6. **外观统一，输入稳定。** 应用内容、浮层与浮窗禁止浏览器原生控件外观，特别是系统滚动条；保留鼠标、键盘与触摸滚动。后台草稿保存不能反复改变操作按钮的几何、明暗或焦点；明确提交、错误和不合法状态仍有真实反馈。反馈固定支持Ctrl/Cmd+Enter，不随普通消息发送偏好改变。系统文件选择与明确点击后的系统打开属于集成边界，详见[UI规范](ui-spec.md)。

## 用户叙事与能力地图

| 用户正在做什么 | 顺手的完成路径 | 需要保住的能力 / 状态 | 本轮具体要求 |
|---|---|---|---|
| 想到一句话，立即记下 | 唤起 → 输入/粘贴 → 发送 → 在附近找到结果 | 草稿、光标、输入法、发送偏好、实际本机提交回执 | 输入贴底；不为“已保存”多留一行；失败可查证重试 |
| 安静地读与写 | 收起导航/专注/检索 → 阅读与继续输入 → 原位恢复 | 阅读位置、筛选、选区、唯一编辑器/写者 | 聊天有完全展开的可能；独立显隐不改计时状态 |
| 开始一段专注 | 在同一对象附近设置名称/时长/到点方式 → 明确开始 | 不同于打开配置的开始动作、合法投影版本 | 配置、切换、反馈不要散落多层；计时卡不孤悬中央 |
| 工作中使用浮窗 | 隐藏主窗专注 → 浮窗暂停/继续/结束/反馈 → 回主窗 | 同一时间块、同一档案/命令身份、持续权威状态 | 不能因隐藏视图而失效；重复命令不重复落事实 |
| 回看一段工作 | 从动作/消息认出来源 → 查看摘要和依据 → 必要时追加反馈 | 人类/Agent/系统来源、原发生时间、引用范围 | 绿/黄/红/蓝等颜色与图形体现动作差异；不可只靠颜色 |
| 找到旧记录 | 按需打开搜索/筛选 → 定位 → 返回阅读 | 搜索内容、页窗口、滚动与上下文 | 不在每次记录时铺满搜索、日期格式、刷新、回顾按钮 |
| 手机/电脑继续同一档案 | 配对授权 → 同步历史 → 查证缺失来源 → 接着工作 | peer身份/游标/父事件、typed timeline、原件状态 | 不用“同步成功”掩盖某一层未到达；有可执行恢复路径 |
| 交付图片或任意文件 | 粘贴/选择 → 看到准备阶段 → 提交 → 预览/打开/分享 | 固定源、hash、已传字节、未知结果/断点 | 图片直接预览；大文件分阶段度量；文本/Markdown换行准确 |
| 调整个人工作方式 | 从设置搜索/命令面板进入 → 改一项 → 原位继续 | 发送键、快捷键、日期/主题/布局各自独立 | 复用 Alpha 已确认行为；反馈 Ctrl/Cmd+Enter 固定 |
| 排查设备与性能 | 安静入口 → 本机总览 → 某项依据 → 可执行恢复/手动导出 | 指标来源、范围、时间、缺测与失败区别 | 本地运维式性能面板；明确 WebView/HTTP API/peer端点用途 |
| 整理多个工作面 | 从侧栏进入模块，未来可拖到独立窗口/标签 | 单写者、档案权限、窗口归属与恢复 | 多窗口/多标签是后续路线，不把独立窗口等同第二套运行服务 |

## 已确认的视觉与交互原则

以用户指定的 `arc-ui-design`（本轮读取版本 0.6.0-alpha.2）为方法来源；实际 skill 路径由运行环境的技能目录提供。仓库统一边界见 [UI 规范](ui-spec.md) 与 [Alpha 复用参考](alpha-ui-ux-reference.md)。

| 原则 | 在外心的具体含义 | 反例与验收关注 |
|---|---|---|
| P01 图形优先 | 用真实 logo、统一矢量操作图标、动作图形/语义色、真实图片预览；保留精确名称/单位与可访问标签 | 全部消息同一橙/灰；用大量常驻解释代替可探索界面 |
| P02 有意义的信息密度 | 关键对象、状态和动作一眼成组，记录占主要阅读面积 | 标题/工具/浮窗入口/区标题/控制/目标/配置逐行叠加；窄小卡片四周大片无意义空白 |
| P03 渐进披露 | 运行地址、来源细节、次要设置和诊断按关注展开 | “本机已保存”永久占输入框下一行；只折叠 JSON 而保留其余常驻噪音 |
| P04 元素独立 | 状态变化不推动输入框/邻项，切换界面不重建写者、选区或阅读窗口 | 1 秒刷新令按钮闪烁；回到页面重新滚到最新 |
| P05 可观察 | 看见真实等待、结果与恢复入口，状态来源可追查 | 用每秒转圈冒充任务推进；为了可观察引入无法解释的能耗 |
| P06 理解→依据→处理 | 日常先认出对象，排障再沿图形关系进入证据与操作 | 无法从概览到具体错误；只给技术码而没有恢复路径 |
| P07 输入等价 | 鼠标、键盘、触摸完成同一语义，IME 不误提交，二值开关名称稳定 | 必须 hover/右键/Ctrl 才能发现关键动作；失焦后继续误触 |
| P08 数据真实 | 暂存/提交/远端接收、缺测/零、过期/实时分开；历史时间不随渲染更新 | 主窗开着便假定浮窗可用；刚收到文本便宣称原件完整 |
| P09 最小困惑 | 入口清楚说明第一次点击结果，控制靠近对象，退出/恢复明确 | “开始”实际上只展开配置；隐藏专注竟令另一窗口失效 |
| P10 有价值的控制 | 可直接操纵、精确输入、取消、反向切换且结果可解释 | 按钮多就当功能丰富；为炫技让常用动作变远 |

品牌要求：任务栏/窗口使用外心真实 logo；侧栏 logo 自身承担折叠切换，不另加重复按钮；版本弱化并入「外心 · 0.6.0 beta12」这类品牌文字，不能把版本和服务地址再铺成主内容标题层。

已核对的历史讨论：[页面即窗口 / 多窗口与标签聚合 #646](https://github.com/exomind-team/exomind/issues/646)、[可退场的沉浸导航 #597](https://github.com/exomind-team/exomind/issues/597)。两项均未因本轮而完成；原议题的窗口身份、订阅成本、关闭/恢复与移动回退边界仍适用。新的用户反馈确认了方向，不自动批准议题中每一项具体动效参数。

## wav2api 对照的迁移边界

用户指定的「从音乐播放到统一路由」线程和三张对照截图属于本轮评审证据；历史指令不自动生效。播放器的价值在于**对象、操作与反馈的关系**，不在于把唱片材质、三栏大图或仪表盘直接照搬到记事界面。

- 播放、提供者供数、画面/物理模拟有不同职责；画面迟到不应阻塞音频。外心对应为 Native计时/同步/传输、数据控制器与视图绘制分离。
- 选歌、试听、定位、暂停是连续任务；既要全功能，也要在关注范围内反复操作。外心对应“记一句→找到刚发的记录→暂停→反馈”。
- 主控制、曲库和信号链各有任务权重；总览小图可进入局部与明细。外心日常阅读保留主内容，运维面板再展开图形诊断。
- 实时图来自真实采样，展开与收起不能伪造事件或改变播放；外心相应保留来源时间、事件与命令身份。
- 稳态时停止不必要的计算和绘制，同时保留供数、恢复与关键检测。外心节能应减少无用绘制/重复查询，不停止被其他表面依赖的业务状态。

上述条目是迁移判断，不能据此宣称两个产品已经通过同等体验验收。

工具各有边界：CodeGraph 用于定位依赖，未覆盖处再读代码；Edge 仿真证明浏览器路径，不能证明 Android 软键盘和物理手感；Tauri MCP 通过已安装 SDK 验证真实宿主 IPC，不把 mock 当 Native；ADB 对实际安装与进程取证；APK/ELF/PE 清单回答构建与存储，不能据此推导电池原因。Astra 提供独立问题清单，人的审美与真实任务签收仍保留。

## 本轮验证门

1. 六种呈现变化：隐藏/折叠专注、简洁记录、切同步、切设置、文档隐藏，均不改数据所有者身份、不发业务命令、不令浮窗状态过期；暂停、继续、追加反馈仍可完成。
2. 数据所有者关闭/切档案后，在途读取不能更新旧表面或复活定时器；失败保留旧证据并可恢复；业务状态刷新不由已隐藏视图重新触发。
3. 短屏测量真实容器中的记录可见面积、可达操作与滚动关系；输入始终可达，配置/取消/提交不丢上下文；截图检查与用户连续操作分开记录。
4. 独立 Astra xhigh 盲审先封存截图初见，再读原则、历史和源码；至少 10 个独立实质问题，每项关联人类任务、证据、影响与验收。主代理仍须核对评审与实现，不能以评审总分自证通过。
