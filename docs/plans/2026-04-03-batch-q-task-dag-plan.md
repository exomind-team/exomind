# #501 收尾批次计划：DAG 结构语义收口

  ## Summary

  本批次是 #501 的收尾批次，范围固定为 #501 + #651 + #661 + #679，目标是在不修正航线的前提下，把 Task DAG 的剩余结构语义工作收成一条可
  实现、可验收、可关单的主线。

  执行顺序固定为：

  1. 理论收口：#661
  2. 理论收口：#651
  3. 工程基线实现：#679
  4. 最小真功能实现：区间收缩 MVP
  5. issue 收口：#651/#661/#679 关闭后，最后关闭 #501

  这轮不是“子任务/父子任务”语义批次，而是区间收缩批次。#501 只作为 umbrella 承接与最终退场，不再扩散新的总范围。

  ## Key Changes

  ### 1. #661 理论结论必须先落地

  产出一份三模式职责合同 + 能力归位表，并同步到计划文档与 issue 评论。

  固定结论：

  - 浏览模式：改变“怎么看 / 怎么认知 / 怎么投影视图”
  - 编辑模式：改变“怎么建立或修改依赖关系”
  - 执行模式：改变“任务此刻如何作用于人”
  - 区间收缩的修改入口属于浏览模式
  - 区间收缩状态跨三模式生效
  - 后续快捷方式不在本批次实现，只先保留浏览模式右键入口

  ### 2. #651 理论结论必须先落地

  产出一份可支持 / 不可支持的区间模式清单，并同步到计划文档与 issue 评论。

  首版支持规则固定为：

  - 名称：区间收缩
  - 基于底层完整图判定，不基于当前可见图
  - 用户从两个节点中任选两端，系统自动判定上下游方向；下游端自动成为“终点”
  - 合法区间必须满足：
      - 整体为单入口单出口 DAG
      - 区间内部节点不得存在边界外依赖
      - 上游边只由起点承接
      - 下游边只由终点承接
  - 不支持时：禁止执行并解释原因
  - 支持多个区间并存，且允许嵌套，不允许部分重叠

  ### 3. #679 作为工程基线先落地

  代码实现阶段，先完成 #679 再做区间收缩。

  固定约束：

  - 所有普通节点与区间收缩后的节点都遵守同一盒模型
  - 使用 160×160 占位盒与统一 60px 间距
  - 区间收缩后的显示也必须兼容这套布局约束，不引入特殊宽度节点

  ### 4. 区间收缩 MVP 的实现合同

  首版实现不是独立聚合节点，而是复用终点节点作为收缩后的载体。

  固定行为：

  - 对外名称统一为 区间收缩
  - 收缩结果附着在终点节点上，不引入任务 truth data 变化
  - 终点节点继续作为主体身份显示，起点只作为标识信息
  - 卡片最少展示：
      - 终点主体
      - 起点标识
      - 成员数
  - 弱交互固定为：
      - 展开/收起
      - 成员摘要
  - 与现有“折叠上游 / 折叠下游”并存但彼此独立
  - 区间收缩状态走本地 UI 持久化
  - 搜索/过滤/聚焦变化导致暂时不可见时，保留区间收缩状态，条件恢复后继续生效
  - 嵌套语义固定为：
      - 内层先成形
      - 外层可以继续包裹
      - 展开外层时，内部已有收缩关系仍保留

  ### 5. 需要新增/调整的接口与状态

  实现阶段应明确新增以下内部接口/状态，不留给实现者自行发明：

  - 一份独立于现有上下游折叠状态的区间收缩视图状态
      - 支持多个区间
      - 支持嵌套
      - 禁止部分重叠
      - 本地 UI 持久化
  - 一套区间合法性校验逻辑
      - 自动判定起点/终点方向
      - 校验单入口单出口
      - 校验内部节点无边界外依赖
      - 产出失败原因文案
  - 一套可见图投影逻辑
      - 将区间收缩结果投影到终点节点
      - 保留起点/终点外部边继承关系
      - 保持与现有聚焦、搜索、终态弱化、上下游折叠并行存在

  ## Test Plan

  ### 自动化

  必须补足以下测试层：

  1. 结构判定测试

  - 任意两端点自动判定上下游方向
  - 合法单入口单出口区间可收缩
  - 内部节点存在边界外依赖时禁止收缩并给出原因
  - 允许嵌套
  - 禁止部分重叠

  2. 图投影测试

  - 收缩后复用终点节点而不是生成独立 truth node
  - 起点标识与成员数正确显示
  - 上游边继承起点
  - 下游边继承终点
  - 搜索/过滤/聚焦变化后，区间收缩状态保留并可恢复

  3. UI 交互测试

  - 浏览模式右键两步选端点
  - 第二个端点选定后立即收缩
  - 不支持模式时出现明确解释
  - 聚合终点节点可展开/收起，并可查看成员摘要
  - 与现有“折叠上游 / 折叠下游”共存不冲突

  4. 布局测试

  - #679 的 160×160 + 60px 约束生效
  - 区间收缩节点也遵守同盒模型
  - 横纵向布局下都不破坏基础间距与盒位

  ### 人工验收

  至少验证：

  - 浏览模式可完成两端点选取并立即触发区间收缩
  - 非法区间会被拦截并解释
  - 合法区间收缩后，终点节点承担收缩态显示
  - 可嵌套收缩，不允许部分重叠
  - 切换搜索/过滤/聚焦后，状态不会丢失
  - 编辑/执行模式不能修改区间收缩，但能看到其结果
  - #679 布局基线没有回归原有 DAG 节点呈现
