# Now Workbench Overlay v2 — 双层气泡设计

> 日期: 2026-03-12
> 状态: 已确认，待实现

---

## 1. 设计目标

将任务悬浮窗从「功能密集的小面板」重构为「双层气泡」，实现：

1. **显示/操作分离** — 气泡层纯只读，hover 后才出现操作面板
2. **视觉轻量化** — 气泡层占用极少屏幕空间，不干扰用户工作
3. **体验一致性** — 与语音悬浮窗统一动画语言（弹性展开、状态图标）
4. **保留现有配色** — 沿用当前 glassmorphic 风格和色彩体系

---

## 2. 状态模型

```
                ┌──────────┐
     开始任务    │          │   hover
  ┌────────────→│  专注中   │←──────┐
  │             │ (running) │       │
  │             └────┬─┬───┘   展开面板
  │            暂停↓  │结束       │
  │             ┌────┘ │    ┌────┴────┐
  │             │暂停中 │    │ 展开层   │
  │             │(paused)│   │(hover)  │
  │             └──┬───┘    └─────────┘
  │           恢复↑ │结束
  │             ┌──┘
  │             ↓
  │  ┌────────────────┐     ┌──────────┐
  │  │  完成反馈(2-3s)  │────→│   空闲    │
  │  └────────────────┘     │  (idle)  │
  │                         └────┬─────┘
  └─────────────────────────────┘
```

### 状态枚举

| 状态 | 对应 model | 气泡表现 |
|------|-----------|---------|
| `running` | `mode === 'running'` && `!paused` | 绿色圆点 + 任务名 + 时间 |
| `paused` | `mode === 'running'` && `paused` | 黄色圆点 + 任务名 + "已暂停" |
| `idle` | `mode === 'idle_with_tasks'` 或 `'idle_input_only'` | 灰色圆点 + 待办列表 |
| `completed` | 结束时间块后临时状态 (2-3秒) | 绿色勾 + 完成信息 |

## 3. 双层结构

### 3.1 气泡层（小状态 / Display View）

**始终可见，纯只读，可拖动。**

#### 专注中 / 暂停中

```
┌───────────────────────────────┐
│ ≡  🟢  写周报    剩45min      │
└───────────────────────────────┘
```

- 状态图标：🟢 进行中 / 🟡 暂停 / ⚪ 空闲 / ✅ 完成
- 时间显示规则：
  - 倒计时模式："剩45min"、"剩1h20m"
  - 正计时模式："已45min"、"已1h20m"
  - 超时："超10min"（使用 destructive 色）
- 数据来源：`model.title` + `resolveRunningClock()` 的简化大致时间格式

#### 空闲

```
┌────────────────┐
│ ≡  ⚪  待办     │
│   · 写周报     │
│   · 修bug      │
│   · 开会       │
└────────────────┘
```

- 竖排列表，显示 `model.visibleTasks.slice(0, 3)`
- 无待办时显示 `⚪ 无待办`

#### 完成反馈（临时状态，2-3秒）

```
┌─────────────────────────────┐
│ ≡  ✅  写周报完成  用时45min  │
└─────────────────────────────┘
```

- 结束时间块后，气泡短暂变为完成卡片
- 2-3秒后自动 fade-out 回到空闲状态
- Agent 反馈等后续功能暂不做

### 3.2 展开层（大状态 / Operation View）

**鼠标 hover 气泡后弹性展开，鼠标离开后收回。**

#### 专注中 hover

```
┌───────────────────────────┐
│ ≡  🟢  写周报              │  ← 拖动区（气泡头部）
│ 剩45min · 预计11:30结束   │  ← 详细时间信息
│ [暂停]  [结束]            │  ← 操作按钮
│───────────────────────────│
│ [输入事件...         🎙️]  │  ← 输入框（文字+语音）
│───────────────────────────│
│ 📝 10:15 完成了设计评审    │  ← 最新一条自己的事件日志
└───────────────────────────┘
```

- 详细时间：剩余时间 + 预计结束时间（来自 `resolveCountdownEndTimeDisplay`）
- 操作按钮：暂停/继续 + 结束（复用现有 handler）
- 输入框：文字输入 + 语音输入按钮（复用 `NowInputRow`）
- 最新事件：`model.recentEvents[0]`，仅显示一条

#### 空闲 hover

```
┌───────────────────────────┐
│ ≡  ⚪  接下来做什么？      │  ← 拖动区
│   · 写周报    [开始]      │  ← 可点击开始任务
│   · 修bug     [开始]      │
│   · 开会      [开始]      │
│───────────────────────────│
│ [输入事件...         🎙️]  │  ← 输入框
└───────────────────────────┘
```

- 任务列表：`model.visibleTasks`，每个带 [开始] 按钮
- 无待办时显示空状态提示 + 输入框

## 4. 交互规则

### 4.1 Hover 展开/收回

| 行为 | 逻辑 |
|------|------|
| 鼠标进入气泡 | 延迟 150ms 后弹性展开面板 |
| 鼠标离开整体 | 延迟 200ms 后弹性收回面板 |
| 输入框获得焦点 | 面板锁定展开，不收回 |
| 输入框失去焦点 + 鼠标不在区域内 | 恢复 200ms 延迟收回 |

### 4.2 拖动

- 拖动热区：气泡头部行（≡ 图标 + 状态圆点 + 标题 + 时间）
- 小状态时：整个气泡可拖动
- 展开状态时：仅头部行可拖动，面板跟随
- 实现：复用现有 `data-tauri-drag-region` + `startDragging()`
- 位置持久化：复用现有 `setNowWorkbenchOverlayPosition()`

### 4.3 结束时间块流程

1. 用户点击 [结束] → 调用 `handleOpenEndDialog()` → `timeBlockService.markEnding()`
2. 气泡变为完成状态 `✅ 写周报完成 用时45min`
3. 2-3秒后自动回到空闲状态
4. 反馈弹窗：v2 暂不做独立反馈弹窗，直接结束

## 5. 动画

| 动画 | 参数 | 时长 |
|------|------|------|
| 展开面板 | spring (stiffness: 300, damping: 24) | ~250ms |
| 收回面板 | spring (stiffness: 300, damping: 24) | ~200ms |
| 完成 pop-in | scale 0.95→1 + opacity 0→1 | ~200ms |
| 完成 fade-out | opacity 1→0 | ~300ms |
| 状态圆点切换 | 颜色渐变 | ~150ms |

实现方式：CSS transition / CSS animation，不引入额外动画库。

## 6. 窗口尺寸

| 状态 | 宽度 | 高度 |
|------|------|------|
| 气泡层（专注中/暂停） | ~280px | ~44px |
| 气泡层（空闲，3个待办） | ~200px | ~110px |
| 展开层（专注中） | ~320px | ~260px |
| 展开层（空闲） | ~320px | ~280px |

**Tauri 窗口策略**：窗口固定为展开层最大尺寸（~320x300px），气泡层通过 CSS 控制内容区域大小，窗口多余部分透明。这样避免频繁调用 Rust 端 resize。

## 8. 配色（沿用现有）

保持当前 glassmorphic 风格，不改变配色体系：

- 背景：`rgba(250,247,245,0.95)` / dark `rgba(28,25,23,0.92)`
- 边框：`border-white/55` / dark `border-white/10`
- 品牌色：`#C75B3A`（按钮、强调）
- 文字：`#1C1917` / dark `#FAFAF9`
- 次要文字：`#A8A29E` / dark `#78716C`
- 毛玻璃：`backdrop-blur-[24px]`

### 状态圆点颜色

| 状态 | 颜色 | CSS |
|------|------|-----|
| 进行中 | 绿色 | `bg-emerald-500` |
| 暂停 | 黄色 | `bg-amber-400` |
| 空闲 | 灰色 | `bg-stone-400` |
| 完成 | 绿色勾 | `text-emerald-500` (CheckCircle icon) |
| 超时 | 红色 | `text-destructive` |

## 9. 验收标准

- [ ] 气泡层：专注中显示状态圆点 + 任务名 + 大致时间
- [ ] 气泡层：暂停时显示黄色圆点 + "已暂停"
- [ ] 气泡层：空闲时竖排显示最近 2-3 个待办任务
- [ ] 气泡层：整块可拖动，位置持久化
- [ ] 展开层：鼠标 hover 气泡后弹性展开
- [ ] 展开层：鼠标离开后延迟收回（200ms）
- [ ] 展开层：输入框获焦时面板锁定不收回
- [ ] 展开层：专注中显示详细时间 + 暂停/结束按钮 + 输入框 + 最新事件
- [ ] 展开层：空闲显示任务列表（带开始按钮）+ 输入框
- [ ] 结束流程：气泡变完成卡片 2-3秒后回空闲
- [ ] 动画：展开/收回 spring 动画流畅
- [ ] 窗口：透明背景，always-on-top，不显示在任务栏
- [ ] 配色：沿用现有 glassmorphic 风格，不改变
