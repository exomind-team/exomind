# Step 7

> Reference only: 该文件仅作为流程参考，不再作为循环输入提示词。实际入口是 `docs/worker-agent/prompts/main.md`。

你现在处理“进入等待更新阻塞态”。

执行要求：

1. 进入等待前确认：
   - 工作区干净，或修改已明确提交
   - 该推送的提交已经推送
   - PR body 已同步
   - 本轮评论已发送
   - 本地状态已更新
2. 调用等待命令：
   - `npx tsx Scripts/dev/worker-agent/index.ts wait-for-update`
   - 若环境提供 bun，也可使用：`bun Scripts/dev/worker-agent/index.ts wait-for-update`
3. 被 reviewer comment / human comment / human test / CI failure 唤醒后，不要停在本步。
4. 唤醒后回到 `main.md`。

完成条件：

- 已进入阻塞等待，或已被唤醒并明确返回 Step 1。
