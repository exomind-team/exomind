### 1.3 整合原则

| 原则 | 说明 |
|------|------|
| **复用优先** | 优先复用现有项目的成熟代码，避免重复造轮子 |
| **渐进式整合** | 分阶段整合，每个阶段产出可运行的最小系统 |
| **统一架构** | 采用 TypeScript + Rust 技术栈，保持架构一致性 |
| **数据兼容** | Fact/Analysis 数据模型统一，记忆系统分层设计 |

## 2. 三个项目核心能力分析

### 2.1 Exo Agents 多代理系统 (`wzy-agents-260203/`)

**项目特点**：
- 文档驱动（文档占比 95.6%）
- 多代理并行运行，各司其职
- 记忆系统分层设计（短期 + 长期 9 领域）
- 双轨健康监控（技术健康 + 成长健康）

**核心模块**：

| 模块 | 文件 | 功能 |
|------|------|------|
| Agent 基类 | `agent.py`, `agent_async.py` | 消息处理、Claude CLI 调用 |
| SSE 通信 | `sse_agent.py`, `sse_agent_cluster.py` | 实时消息流式传输 |
| 记忆系统 | `memory/*.md` | 9 个分领域长期记忆 |
| RSS 收集 | `rss_infosource_collector/` | 信息源采集与整理 |

**提取复用**：
- Agent 基类架构
- SSE 客户端实现
- 记忆系统设计模式
- 健康检查机制

### 2.2 ExoBuffer Connector (`ExoBuffer-Connector/`)

**核心定位**：
- 事件采集与实时同步系统
- Append-only 数据存储
- SSE 多客户端实时广播

**数据模型**：

```typescript
// Fact - 事实记录
interface Fact {
  fact_id: string;      // 格式: f-{uuid}
  timestamp: number;    // 毫秒级 Unix 时间戳
  source: 'manual' | 'api' | 'tool';
  content_type: 'text' | 'url';
  content: string;      // 原始内容，禁止加工
  meta: FactMeta;
}

// Analysis - 分析结果
interface Analysis {
  analysis_id: string;  // 格式: a-{uuid}
  fact_id: string;      // 关联的 Fact
  analysis_type: 'sentiment' | 'note' | 'hint' | 'link';
  result: string;
  confidence: number;   // 0.0 - 1.0
}
```

**核心功能**：
- POST `/api/fact` - 创建 Fact
- GET `/api/facts` - 获取列表（支持过滤）
- SSE `/api/events` - 实时事件流
- 话题标签 + 关键词过滤

**提取复用**：
- Fact/Analysis 数据模型
- SSE 广播机制
- JSONL 存储策略
- 消息过滤语法

### 2.3 语音 IME 模块 (`exomind-model/`)

**核心能力**：
- 云端语音识别（ASR）
- 文本转语音（TTS）

**集成策略**：
- 优先使用云端 API（不考虑本地模型）
- ASR 结果直接输入 Agent
- TTS 输出 Agent 语音响应

## 3. 分阶段开发计划

### 3.1 阶段一：Agent 核心框架 (Week 1)

**目标**：构建可运行的 Agent 基础框架，实现 Claude Code 流式输入输出解析

**时间**：2026-02-03 ~ 2026-02-09

1. Agent 基类（TypeScript 实现）
2. SSE 客户端（流式响应解析）
3. 基础消息队列

**任务分解**：

| 任务 | 说明 | 来源 |
|------|------|------|
| Agent 基类重构 | 从 Python 迁移到 TypeScript | wzy-agents |
| SSE 客户端实现 | 流式解析 Claude Code 输出 | wzy-agents |

### 3.4 阶段四：健康监控 (Week 4)

**目标**：实现双轨健康监控系统

**时间**：2026-02-24 ~ 2026-03-02

**交付物**：
1. 技术健康指标（空之度量 + 时之度量）
2. 成长健康指标（目标对齐度 + 记忆转化率）
3. 健康报告生成

**任务分解**：

| 任务 | 说明 | 来源 |
|------|------|------|
| 空之度量 | 空间维度指标 | wzy-agents |
| 时之度量 | 时间维度指标 | wzy-agents |
| 成长健康 | 软件层面指标 | wzy-agents |
| 健康报告 | 日/周报生成 | wzy-agents |

**健康指标**：

| 轨道 | 指标 | 计算方式 | 健康阈值 |
|------|------|----------|----------|
| **技术健康** | 缓存命中率 | 缓存读取 / 总输入 | > 80% |
| **技术健康** | 成本/轮 | 累计成本 / 对话轮数 | 稳定 |
| **成长健康** | 目标对齐度 | 有效输出 / 总交互 | > 50% |
| **成长健康** | 记忆转化率 | 短期→长期转换率 | > 30% |

**验收标准**：
- [ ] 能计算各项健康指标
- [ ] 能生成健康报告
- [ ] 指标异常能告警
