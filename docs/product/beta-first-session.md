# 第一次在 0.6 Beta 记一件事

准备一段容易认出的短文字和一张小图片。用它们测试本机记录，再决定是否要带第二台设备加入。选择安装包时核对版本与平台，候选和公开发行的来源可在版本页查到。[版本状态](../AI-CONTEXT.md)

## 在本机保存记录

1. 打开外心，进入「选择或创建档案」。首次使用时输入一个容易认的名称并点「创建档案」。已有资料时选择原档案，同名档案可以各自持有独立内容。
2. 在「当下」输入一条记录，选择图片。看到「附件已校验就绪」表示这张图已准备好。点击发送，等本机保存完成，再从历史打开该条记录和图片。较早的候选在读取剪贴板时可用的操作有所不同。
3. 如果画面仍提示「结果待确认」，保留当前记录，使用界面提供的查证或重试入口。如果提示「本机源缺失」，重新选择原文件。状态和提交边界见[记录合同](../development/v0.6-beta-core-contract.md)。

## 用时间块记录一次专注

给时间块起名后开始计时。暂停和继续对应同一块；行动结束后可以填反馈或明确跳过。倒计时的「继续超时」与「结束行动并待反馈」会产生不同的后续状态，按本次活动选择。遇到时间显示过期时先等服务刷新，起止记录以该档案的实际时间块为准。[时间块与窗口职责](../development/beta-native-workspace.md)

## 在另一台设备接手

在持有目标档案的一端生成邀请，在接收端检查邀请、核对来源并确认加入。使用同一候选进行对照，保留两端已有档案和刚才的试件。依次在接收端找到同一条文字、查看时间块，再实际打开原图。这样能确定资料已经到了哪一步。[附近设备与加入](../development/beta-nearby-discovery.md) · [原件查看与获取](../development/beta-original-diagnostics.md)

| 看到的情况 | 能确认的结果与下一步 |
|---|---|
| 邀请可检查，成员仍待确认 | 核对档案和来源后再确认加入。 |
| 文字到了，原图还在等待 | 文字已在这端可读。查看图片的传输状态与持有端，保留源端的可用副本。 |
| 需要把档案带到另一台电脑 | 选择档案备份与导入。先看预览里的事实、来源证明和原件完整度，再确认；只想给人看几条记录时使用选取内容导出。[导出指南](../development/beta-user-exports.md) |
