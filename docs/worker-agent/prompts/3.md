# Step 3

你现在处理“刷新 PR 真相与 review 增量”。

执行要求：

1. 刷新当前 PR 的：
   - head SHA
   - reviewer comments
   - reviews / review threads
   - human comments
   - `🙋needs-human-test`
   - CI failure
2. 把新增项按阻塞优先级整理出来。
3. 若存在未处理阻塞项，明确列出并停止进入开发步骤。
4. 若没有阻塞项，说明可以进入下一步开发。

参考：

- `docs/development/worker-agent/review-flow.md`

完成条件：

- 已给出“有阻塞 / 无阻塞”的明确判断。
