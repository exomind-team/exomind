# 安全与运行边界

## 默认范围

默认只绑定 loopback，所有业务 API 要求 Bearer token。健康接口与静态页面公开，但健康不等于获得数据权限。不开放任意浏览器 Origin/CORS；校验 Host，防止把来自任意网站的请求当作本机控制。此候选未经独立安全审计。

owner 是本机管理权限；observer 只读业务；writer 可记录和控制时间块，但不能管理配对/密钥/总结任务；peer 只读有限同步协议。所有角色目前均为**当前空间级**，没有细粒度逐记录授权。外部工具只能用真正需要的独立令牌。

## 跨设备

远程默认要求 HTTPS，Node 正常验证证书与主机名。可显式信任通过受信渠道取得的 CA PEM；不能使用忽略 TLS 验证。配对邀请是十分钟 bearer 能力，既含地址也含临时秘密。配对信任来自用户的受信渠道，不是 IP 地址或 mDNS 名称。

`--allow-trusted-http` 是明确的私网实验豁免，数据和令牌在 HTTP 层为明文。即使由 EasyTier 承载，也只可在核对网络参与者、虚拟网络隔离、防火墙和流量路径后使用；本候选不自动验证 VPN 配置。不绑定公网，不做 UPnP/端口映射。

暂停/撤销会中止旧请求的本地应用资格。撤销本机凭据不撤销别人已经拿走的数据，不承诺远程擦除。地址更新保留稳定身份，若响应设备/空间/epoch 不匹配会拒绝继续补齐。

## 本机文件

SQLite、附件、连接描述符和模型证据都属于私有内容。POSIX 使用 0700 目录/0600 文件；**Windows chmod 不等于配置 NTFS ACL**，必须由本地 Agent 验证目录权限与用户隔离。磁盘数据不加密，依赖 OS 访问控制/磁盘加密；同一登录用户的恶意进程不在本包隔离能力内。

`--open` 通过浏览器 URL fragment 传递本机令牌，页面移除 fragment；HTTP 请求和服务日志不包含它。但本机进程参数、浏览器扩展/标签历史可能观察它，不能称为 OS 密钥库。也可不使用 `--open`，手动输入令牌。

不要复制正在使用的整个数据目录作为第二个独立设备：这会复制身份和密钥。使用可移植恢复生成新身份。一个目录只运行一个 Runtime；文件锁是启动防误用，不是跨主机锁或分布式租约，不能把数据目录放网络共享盘。

## 附件与外部执行

仅接受受限长度、无路径控制符的文件名。附件以哈希路径存放，下载用 octet-stream；只对 png/jpeg/webp/gif 做图像预览，不执行 HTML/SVG。附件名/MIME 不是可信内容证明。没有压缩包自动解压、网页抓取、Shell 工具或自动启动附件。

单文件 64 MiB、单记录 16 附件、分块 256 KiB 是候选预算，不是产品永久限制。浏览器计算哈希/预览可能同时持有多个内存副本，大图与多文件的内存/卡顿必须实测。中断上传可留下 staging；本包不做自动清理，防止未经授权删除资料。

## 模型与诊断

只有显式配置的模型才会收到本机文字证据快照。API 密钥来自环境，不写入导出快照。附件仅发送元数据，不读取媒体正文。输入含提示注入风险，因此模型没有任意动作工具；严格输出校验也不能替代语义审核。

诊断不输出 token、正文或模型密钥，但仍含设备 UUID、地址与故障元信息；分享前脱敏。详细底层错误的结构化上下文仍有改进空间；本版日志优先避免泄露数据。不存在“测试通过即安全认证”。
