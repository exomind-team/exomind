# ExoMind 使用指南

## 快速开始

1. 访问 **事件日志** 页面
2. 输入你的想法或内容
3. 使用语音输入快速记录

## 功能介绍

### 事件日志
记录你的思想、任务和灵感。支持 Markdown 格式。

### 语音输入
- 点击麦克风按钮开始录音
- 再次点击停止录音
- 自动识别语音并转换为文字

### ASR 测试
测试语音识别功能，验证麦克风和工作流。

## 快捷键

| 按键 | 功能 |
|------|------|
| `空格` | 开始/停止录音 |
| `Esc` | 取消录音 |

## 常见问题

**麦克风权限被拒绝？**
- Chrome: 点击地址栏左侧锁图标 → 权限 → 麦克风 → 允许
- 移动端: 设置 → 应用 → Chrome → 权限 → 麦克风

**语音无法识别？**
- 确保网络连接正常
- 说话清晰，语速适中
- 减少背景噪音
