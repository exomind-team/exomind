# 本轮范围与架构决定

## 事实基线

本候选按用户 2026-11-10 明确授权及脱敏交接包重新收束产品，不把旧宏伟路线全量搬入。主仓源码参考为 `ddb1ba1a6c1e0760af77b55d5659df44ad253b34`，并非日用程序包一致性的证明。

## 本轮工程选择，不冒充永久产品决定

**Node Web-first 参考 Runtime。** 当前可执行环境只有 Node22.16，无 Rust 工具链。先实现并跑通语义，而不是提交一批未编译的原生代码。未来原生实现可复用合同和测试夹具，不必把这个临时候选自动当成最终技术栈。Node sidecar 会引入 Android、启动资源、更新与安装维护成本，不能隐瞒。

**一实例一空间。** 当前不实现账户、Archive OS 或复杂多空间 UI。设备身份、空间身份、端点各自分离。设备改地址不改身份；只有空实例可加入新空间。使用不同数据目录隔离试验；不合并两个已写入的空间。

**不变记录＋领域投影。** 捕获、开始、结束、反馈、总结都追加。没有多对象通用 CRDT 依赖，也不把将来复杂可编辑对象伪装成已经解决。原始记录是权威；当前时间块只是查询投影；浏览器关闭后仍可查询和推进。

**冲突可见优先。** 离线同时开始保留两个事实；同一块两个结束保留分叉；同 ID 不同内容隔离，停止推进该对端游标。当前没有自动冲突决议 UI；隔离后必须按诊断取证，不允许“删库重来”作为默认修复。

**小型总结循环。** 起止边界、证据查询、预算、状态、校验由确定性代码控制，模型只产生有限结构化回顾。由产生结束记录的设备自动处理；不增加分布式任务调度。远端事后追加的反馈会同步，但不会自动唤起另一设备的新总结；这是已公开的首版限制。

**不吸收外部软件的职责。** WinCraft 拥有窗口；外心只供状态。Obsidian 接口尚未实现，当前只提供中立 JSONL＋附件快照，不宣称已打通知识库。EasyTier 只为端点提供可达性，外心仍负责身份、认证、补齐、冲突和落盘。

## 关键不变量与用户语义

| 不变量 | 用户可理解的含义 | 保障位置 |
|---|---|---|
| receipt 与命令结果同一事务 | “本机已保存”不是乐观 UI | Store.command |
| 相同 ID 的请求内容不变 | 重试不是再记一份 | commands.input_hash |
| 附件验证完成才提交本机记录 | 未传完文件不假报整条保存 | Blobs＋capture |
| 远端元数据与附件可分阶段到达 | 文字先出现，附件明确等待 | SyncEngine |
| 远端页应用与 cursor 同事务 | 半页失败不能跳过后面的记录 | applyRemote |
| 历史前缀和 epoch 可检查 | 恢复旧库不假装已同步最新 | checkpoint/hash chain |
| 联机状态不等于信任关系 | 设备离线不会被自动忘掉 | peers 持久表 |
| 取消/更代后的结果不能提交 | 停止了就不悄悄写入 | job.run_id / peer.generation |
| 读取失败与空集合不同 | 没读到不表示没发生 | 异常与 coverage |

SHA-256 用于内容一致性，不是数字签名，也不证明 author 字段来自某个真实人。配对设备是受信写入者；不提供恶意成员间的不可抵赖性。
