## 六、经验总结

### 6.1 学到的经验

1. **Tauri Android 构建**：需要 Java 17，Gradle daemon 可能有问题时加 `--no-daemon`
2. **多设备处理**：ADB 多设备时用 `-s` 指定设备 ID
3. **路径问题**：Windows 路径在 PowerShell 和 Bash 中处理方式不同
4. **签名问题**：Debug APK 自动签名，Release APK 需要手动签名

### 6.2 脚本最佳实践

| 实践 | 说明 |
|------|------|
| **自动环境设置** | 脚本自动设置 JAVA_HOME，避免用户手动配置 |
| **分阶段计时** | 每个构建阶段单独计时，便于优化 |
| **自动日志** | 构建日志保存到 `build-logs/` 目录 |
| **完成提示** | 构建完成后播放提示音 |

### 6.3 模板复用方法

```
# 方法1：直接复制（推荐）
xcopy /E /I tauri-app new-project
# 修改配置 → 安装依赖 → 开发

# 方法2：CLI + 脚本移植
bun create tauri-app new-project
copy build-*.ps1 new-project/
# 修改配置 → 完成
```
