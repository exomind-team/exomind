# 📖 ExoMind 使用指南

> 生命成长助手 - 记录、思考、成长

---

## 🚀 快速开始

只需 3 步即可开始使用：

1. 📝 **记录想法** - 在事件日志中输入你的想法、任务或灵感
2. 🎤 **语音输入** - 点击麦克风按钮，用语音快速记录
3. 📊 **回顾成长** - 随时查看历史记录，反思你的成长轨迹

---

## ✨ 功能介绍

### 📋 事件日志

> 记录你的思想、任务和灵感

| 特性 | 说明 |
|------|------|
| **文本输入** | 支持 Markdown 格式，包括加粗、斜体、列表等 |
| **语音输入** | 点击麦克风按钮开始录音，自动转换为文字 |
| **标签管理** | 为事件添加标签，便于分类和检索 |
| **时间线视图** | 按时间顺序展示你的记录历史 |

### 🎤 语音输入

> 解放双手，用声音快速记录

**使用方法：**
- 🔘 点击麦克风按钮开始录音
- ⏹️ 再次点击停止录音
- ⏳ 等待语音识别完成
- ✏️ 识别结果会自动填入输入框

**状态指示：**

| 状态 | 图标 | 说明 |
|------|------|------|
| 空闲 | 🎤 | 准备开始录音 |
| 录音中 | 🔴 | 麦克风正在工作 |
| 识别中 | ⏳ | 正在处理语音 |
| 完成 | ✅ | 识别结果已生成 |

### ⚙️ 设置

> 配置你的个性化偏好

- 🔑 **API Key 配置** - 设置 MOSS ASR 服务密钥
- 🎨 **主题切换** - 明亮/暗黑模式
- ⌨️ **快捷键** - 自定义键盘快捷键

## ⌨️ 快捷键

| 场景 | 条件 | 按键 | 功能 | 说明 |
|------|------|------|------|------|
| 语音输入 | 非输入区域 | `空格` | 开始/停止录音 | 在非输入区域生效 |
| 语音输入 | 录音中 | `Esc` | 取消录音 | 录音中按 Esc 取消 |
| 事件记录 | 输入框未聚焦 | `Enter` | 聚焦事件输入框 | 快速开始输入「输入内容记录事件」 |
| 事件记录 | 输入框未聚焦 | `Shift+Enter` | 聚焦时间块名称输入框 | 自动展开 TimeBlock 并聚焦「任务标题」 |
| 事件记录 | 事件输入框已聚焦且无内容 | `Enter` | 开始语音录音 | 等价点击 🎤 按钮 |
| 时间块 | 时间块名称输入框有内容 | `Enter` | 开始时间块 | 多行输入：首行作为名称，其余作为描述写入开始事件 |
| 时间块 | 时间块名称输入框已聚焦 | `Shift+Enter` | 换行 | 在时间块名称输入框内新增一行 |
| 时间块 | 时间块名称为空 | 点击「开始」 | 聚焦时间块名称输入框 | 自动展开 TimeBlock 并聚焦「任务标题」 |
| 时间块 | 时间块结束弹窗（身心反馈输入框已聚焦） | `Enter` | 确认结束 | 等价点击「确认结束」 |
| 时间块 | 时间块结束弹窗（身心反馈输入框已聚焦） | `Shift+Enter` / `Ctrl+Enter` | 换行 | 多行记录身心反馈 |

## ❓ 常见问题

### 🎤 麦克风权限被拒绝？

**Chrome 桌面版：**
1. 点击地址栏左侧的 🔒 锁图标
2. 选择「权限」→「麦克风」
3. 选择「允许」
4. 刷新页面重试

**Android Chrome：**
1. 打开系统「设置」→「应用」
2. 找到「Chrome」→「权限」
3. 允许「麦克风」权限
4. 或者在 Chrome 地址栏输入 `chrome://flags`
5. 启用 `unsafely-treat-insecure-origin-as-secure`
6. 添加你的本地地址（如 `http://192.168.x.x:1420`）
7. 重启浏览器

### 🔇 语音无法识别？

**请检查以下几点：**

- 🌐 **网络连接** - 语音识别需要联网
- 🎙️ **麦克风位置** - 确保麦克风未被遮挡
- 🗣️ **说话方式** - 语速适中，发音清晰
- 🔊 **环境噪音** - 尽量在安静环境中使用
- 📶 **网络质量** - 良好的网络连接有助于识别准确率

### 📱 移动端使用注意事项

1. **HTTPS 要求** - 语音功能需要安全上下文
2. **权限设置** - 确保已授予麦克风权限
3. **浏览器选择** - 推荐使用 Chrome
4. **省电模式** - 关闭省电模式以确保录音正常

## 💡 使用技巧

> 最大化你的使用效率

### 📝 记录技巧

- ✨ 使用 **加粗** 强调重要事项
- 📝 创建 **待办列表** 追踪任务进度
- 🏷️ 添加 **标签** 便于后续检索
- 💭 记录 **感受和思考**，不只是事实

### 🎤 语音技巧

- 🏠 找一个安静的环境
- 🎯 说话清晰，语速适中
- 📏 距离麦克风 15-30cm
- ⏸️ 适当停顿，让系统识别完整句子
