# 外心目标系统补充规格：连边角分离力

> 关联 issue：[#747](https://github.com/exomind-team/exomind/issues/747)
>
> 定位：目标网络力导向布局的补充力系设计。当前阶段用于增强局部结构展开；不改变 #747 既有渲染稳定性验收口径。

## 1. 背景

当前目标网络已有三类主要力：

- `Me-goal`：围绕 `Me` 的 hop 圈层约束
- `goal-goal`：目标节点之间的远近关系
- `spring-link`：连边牵引力

在此基础上，仍存在一个结构性缺口：

- 星形局部缺少“邻边均匀展开”的趋势
- 链式局部缺少“中间节点两侧边趋向共线”的趋势
- 现有节点级排斥力更偏向控制距离，不直接表达“边与边应该拉开角度”的目标

因此引入一套新的局部力系：`edge-separation`（连边角分离力）。

## 2. 目标

`edge-separation` 的目标是补充“共享端点的连边角分离”趋势：

- 对星形网络，中心节点与各外层节点的夹角应趋向近似均匀
- 对三点链 `A-B-C`，中间节点 `B` 两侧的边 `BA` 与 `BC` 应倾向形成更接近直线的结构，即 `∠ABC` 倾向 `180°`
- 在不打坏现有圈层、可见性、居中、收敛约束的前提下，让局部结构更清晰、更少拥挤

## 3. 非目标

当前阶段 `edge-separation` 不负责：

- 替代 `Me-goal` hop 圈层约束
- 替代 `spring-link` 边长牵引
- 直接改变 #747 现有 E2E 验收口径
- 处理不共享端点的边对

后续若实验结果表明该力已足够承担局部结构展开作用，可再讨论逐步弱化、甚至部分替代 `goal-goal` 力。

## 4. 作用范围

`edge-separation` 仅作用于“共享同一端点”的逻辑边对。

示例：

- `A-B` 与 `A-C`：参与计算
- `Me-A` 与 `Me-B`：参与计算
- `A-B` 与 `C-D`：不参与计算

### 4.1 Me 节点

- `Me` 相关边参与角分离计算
- `Me` 本身保持固定，不接受该力带来的位置变化
- 当共享端点为 `Me` 时，分离力只传导到对端目标节点

### 4.2 重边

- 重边在角分离逻辑上按一条逻辑边处理
- 不因重边数量重复占据多个角位置
- 当前阶段不引入重边额外乘数；先保持最小可控实现

### 4.3 可见性边界

- `edge-separation` 只基于当前可见图参与计算
- 已取消且当前被隐藏的节点/边，不参与角占位与分离力计算
- 这条规则与当前布局系统的 visible graph / hidden edge 处理保持一致，避免可见节点被不可见结构“遥控”而破坏 #747 的渲染稳定性约束

## 5. 力模型

对任一共享端点 `P`，收集其所有 incident logical edges，记为若干条射线 `P-X`。

对每一对射线 `(P-A, P-B)`：

1. 取单位向量：
   - `uA = normalize(A - P)`
   - `uB = normalize(B - P)`
2. 计算：
   - `dot = clamp(uA · uB, -1, 1)`
   - `cross = uA.x * uB.y - uA.y * uB.x`
3. 定义角压缩量：
   - `compression = (1 + dot) / 2`

含义：

- 两条边几乎重合时，`dot ≈ 1`，`compression` 接近最大，角分离力最大
- 两条边接近 `180°` 时，`dot ≈ -1`，`compression` 接近 `0`，角分离力接近 `0`

### 5.1 受力方向

该力只提供切向分量，不提供径向分量。

- 若 `cross > 0`，则 `P-B` 在 `P-A` 的逆时针侧
  - `A` 受顺时针切向力
  - `B` 受逆时针切向力
- 若 `cross < 0`，方向反转
- 若 `cross ≈ 0`，使用稳定 fallback 符号，避免共线时抖动或方向翻转

### 5.3 退化情形的稳定 tie-break

当两条射线近乎共线，导致 `cross ≈ 0` 时，方向不再由瞬时浮点结果决定，而由稳定顺序决定：

- 先对逻辑边按 `(sharedEndpointId, otherEndpointId)` 做稳定排序
- 若两条边共线，则排序在前者默认取顺时针切向，排序在后者默认取逆时针切向
- 相同输入图在相同初值下，应得到相同 fallback 方向，不允许因浏览器浮点噪声频繁翻转

### 5.2 受力分配

- 该力默认只施加到射线另一端节点 `A`、`B`
- 共享端点 `P` 默认不直接受这股力推动
- 这样可天然满足 `Me` 固定的约束，也能减少局部扭矩对整体收敛稳定性的破坏

### 5.4 固定节点语义

- 除 `Me` 之外，任何当前已固定的节点（如已有 `fx/fy` 的拖拽/钉住节点）也应被视为不可被该力直接推动
- 若一对角分离边的对端之一为固定节点，则只把对应切向力传导给另一端的可动节点
- 若两端都固定，则该边对不产生可移动位移

## 6. 与现有力系的关系

当前阶段采用“共存，不替代”的策略：

- 保留现有 `Me-goal`
- 保留现有 `goal-goal`
- 保留现有 `spring-link`
- 新增 `edge-separation`

接入原则：

- `edge-separation` 只调整局部方向分布
- hop 圈层、边长牵引、全局可见性与收敛仍由现有力系主导
- 初始强度与当前目标节点间排斥力处于同一量级，但单独参数化，便于独立实验

## 7. 参数策略

新增独立参数，例如：

- `EDGE_SEPARATION_STRENGTH`

阶段策略：

1. 初值先对齐当前 `goal-goal` 近距排斥力量级
2. 先只观察“局部结构是否明显展开”
3. 后续再单独控制变量，比较：
   - 保持共存
   - 弱化 `goal-goal`
   - 部分由 `edge-separation` 替代 `goal-goal`

## 8. 测试策略

### 8.1 单元冒烟测试

每类力都应有自己的单元冒烟测试，当前统一从最小三点模型 `Me-A-B` 开始。

目标不是一开始锁死最终几何，而是验证：

- 力开启后节点位置确实发生变化
- 多跑若干 tick 后系统稳定，不发散、不出现 `NaN`
- 预期受力对象发生位移，固定节点仍保持固定

建议为每一类现有力都建立最小冒烟测试，并在 #747 记录“为何认为该力起效”的观测依据：

| 力 | 最小模型 | 冒烟观察点 | 视为起效的依据 |
|----|---------|-----------|---------------|
| `Me-goal` | `Me-A-B` | `A`、`B` 会被推向各自 hop 目标圈层 | 在若干 tick 后，`dist(Me,A)`、`dist(Me,B)` 明显偏离初值并趋向各自目标层，系统未发散 |
| `goal-goal`（近距） | `Me-A-B` | 目标之间会按 hop 关系相互排斥 | 打开该力后，`A-B` 距离相对关闭时有可测变化，且方向符合近距关系预期 |
| `spring-link` | `Me-A-B` | 连边两端会产生牵引 | 打开该力后，边长相对关闭时向目标长度收敛，未出现异常抖动 |
| `edge-separation` | `Me-A-B` | 共享端点的两条边会切向拉开 | 打开该力后，夹角增大、`Me` 仍固定、位置变化稳定且无数值异常 |

补充说明：

- 用户要求当前优先从 `Me-A-B` 三点模型开始，因此所有“可在三点模型表达的主力行为”都先以该模型建立冒烟验证
- 对三点模型无法表达的子类型或辅助力（例如 `goal-goal-far-attract`、`collide` 等），允许使用最小必要扩展模型补充验证，但不取代三点冒烟测试在主链路中的优先级

对 `edge-separation` 的最小验证包括：

- `Me` 为共享端点时：
  - `Me-A` 与 `Me-B` 会被切向拉开
  - `Me` 本身不移动
- 普通节点为共享端点时：
  - 三点链中的中间节点两侧边夹角会增大
- 接近共线、接近重合时不会数值炸裂

### 8.2 集成 / E2E

`#747` 现有约束继续保留，当前不因引入 `edge-separation` 而放宽：

- `Me` 在同心圆中心保持不动
- 同心圆完整独立呈现
- 节点隐藏 / 连边隐藏的渲染稳定性问题继续受约束
- 既有收敛与布局稳定性检查继续有效

在此基础上，新增结构性实验应先从三点模型开始，再扩展到星形模型。

## 9. 落地顺序

1. 在 issue #747 中记录本设计，作为后续实验约束来源
2. 为所有现有力补最小三点单元冒烟测试，并在 #747 中记录每类力“为何判定其起效”
3. 为 `edge-separation` 补最小三点单元冒烟测试
4. 以 TDD 实现 `edge-separation`
5. 先验证它与现有力系共存不破坏 #747
6. 再逐步调参与比较是否有必要弱化部分 `goal-goal` 力

## 10. 当前结论

`edge-separation` 本质上是一套“共享端点的局部角分离力”，适合先作为独立新系统叠加到现有布局里。

当前结论明确为：

- 先共存，再调参
- 先做三点模型冒烟验证
- 先保持 #747 既有验收口径不变
- 后续若实验效果稳定，再讨论替代部分目标间力
