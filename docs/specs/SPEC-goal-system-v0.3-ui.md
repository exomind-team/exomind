## 1. 视图架构

### 1.1 主视图：目标网络（力导向图）

整个目标系统的主交互界面是一个画布式的力导向图：

- **节点**：Me（固定中心）+ 目标节点（外围）
- **边**：任务边（有向，箭头指向 target）
- **布局**：d3-force 物理模拟

### 1.2 辅助面板：详情面板

点击节点或边后弹出的侧边/底部面板，展示和编辑属性。

### 1.3 未来视图：星图视图

概念视图，本版本不实现，仅保留设计意向。

## 2. 力导向布局

### 2.1 物理模拟参数

| 力 | 作用 | 说明 |
|----|------|------|
| 排斥力 | 目标节点间相互排斥 | 防止重叠 |
| 链接约束 | 任务边约束两端距离 | 连接的节点不会飞太远 |
| 中心力 | Me 固定在画布中心 | Me 坐标 (0, 0)，不参与物理模拟 |

### 2.2 距离语义（视觉呈现）

逻辑层提供 `getHopDistance(goalId)` → UI 层用此值：

- 渲染距离标尺（同心圆或径向刻度）
- 近（1跳）= 近期目标，远（多跳）= 长期目标
- 标尺方向：Me 向外，越远越长期

### 2.3 节点视觉

| 节点类型 | 外观 | 状态映射 |
|----------|------|---------|
| Me | 特殊样式（大圆、高亮） | 始终显示 |
| 目标-pending | 默认样式 | 可交互 |
| 目标-completed | 完成样式（绿色/打勾） | 吸纳动画后淡化 |
| 目标-cancelled | 取消样式（灰色/删除线） | 半透明 |

### 2.4 边视觉

| 边状态 | 外观 | 说明 |
|--------|------|------|
| pending | 虚线 | 尚未开始 |
| in_progress | 实线 + 高亮色 | 正在进行 |
| suspended | 虚线 + 暗色 | 已挂起 |
| completed | 实线 + 完成色 | 已完成 |
| cancelled | 极淡/半透明 | 已取消 |
| 匿名边 | 细虚线 + 「待命名」标签 | taskNodeRef 为空 |

## 3. 用户操作 → 逻辑 API 映射

### 3.1 添加目标

| 交互 | 逻辑调用 |
|------|---------|
| 点击画布空白处 | `createGoal({ title: '' })` → 弹出重命名输入框 |

### 3.2 添加任务边（连线）

| 交互 | 逻辑调用 |
|------|---------|
| 从节点 A 拖拽到节点 B | `createEdge({ source: A.id, target: B.id })` |

**失败处理**：
- DAG 检测失败 → 提示「不能形成环」，取消操作
- 自环 → 提示「不能连到自己」

### 3.3 编辑属性

| 交互 | 逻辑调用 |
|------|---------|
| 详情面板修改目标标题 | `updateGoal({ goalId, title })` |
| 详情面板修改 AND/OR | `updateGoal({ goalId, achieveMode })` |
| 详情面板修改边标题 | `updateEdge({ edgeId, title })` |
| 详情面板修改边状态 | `updateEdgeStatus({ edgeId, newStatus })` |

### 3.4 取消目标

| 交互 | 逻辑调用 |
|------|---------|
| 右键菜单 → 取消目标 | **弹窗确认**：「是否同时取消关联任务？」→ `cancelGoal({ goalId, cascadeEdges: 用户选择 })` |

> 这是逻辑层 `cascadeEdges` 参数在 UI 层的实现：弹窗让用户选择。

### 3.5 删除任务边

| 交互 | 逻辑调用 |
|------|---------|
| 右键菜单 → 删除任务 | `deleteEdge({ edgeId })` |

### 3.6 拆解边

| 交互 | 逻辑调用 |
|------|---------|
| 右键边 → 拆解 | 弹窗：选择「新建中间目标」或「选已有目标」+ 原边分配 → `splitEdge({ edgeId, ... })` |

### 3.7 画布操作

| 交互 | 说明 |
|------|------|
| 拖拽节点 | 改变物理模拟位置，松手后继续模拟 |
| 缩放 | 鼠标滚轮 / 双指缩放 |
| 平移 | 拖拽画布空白 |

## 4. 详情面板

### 4.1 目标详情

| 字段 | 展示 | 可编辑 | 说明 |
|------|------|--------|------|
| title | 标题（待命名时显示占位文字） | ✅ | |
| description | 描述 | ✅ | |
| status | 状态标签 | ❌ | 纯显示（C8：不可手动完成） |
| achieveMode | AND/OR 切换 | ✅ | |
| 入边列表 | 指向该目标的任务 | — | 可点击跳转 |
| 出边列表 | 从该目标出发的任务 | — | 可点击跳转 |
| 跳数距离 | Me 到该目标的最短跳数 | ❌ | 调用 getHopDistance |

### 4.2 任务边详情

| 字段 | 展示 | 可编辑 | 说明 |
|------|------|--------|------|
| title | 标题 | ✅ | |
| description | 描述 | ✅ | |
| status | 状态 + 可选转移按钮 | ✅（合法转移） | 按 §3.1 状态机 |
| source | 源节点名称 | ❌ | 可点击跳转 |
| target | 目标节点名称 | ❌ | 可点击跳转 |
| taskNodeRef | 关联任务 | ✅ | 后续集成 |

## 5. 视觉特效

### 5.1 吸纳动画

当目标达成推导为 completed 时：

1. 目标节点向 Me 移动（动画 ~500ms）
2. 缩小并淡入 Me 圆
3. Me 圆短暂脉冲发光
4. 目标节点保留在图中但切换为 completed 样式

### 5.2 级联传播视觉

达成推导沿 DAG 传播时，沿传播路径的边短暂高亮闪烁，帮助用户理解「为什么这个目标突然完成了」。

### 5.3 待命名提示

title 为空的节点/边显示半透明的「待命名」占位文字，点击即进入编辑模式。

## 6. 右键菜单

### 6.1 目标节点右键

| 菜单项 | 可用条件 | 动作 |
|--------|---------|------|
| 编辑 | 总是 | 打开详情面板 |
| 取消目标 | status = pending | 弹窗确认 → cancelGoal |
| 连接到... | status = pending | 进入连线模式 |

### 6.2 任务边右键

| 菜单项 | 可用条件 | 动作 |
|--------|---------|------|
| 编辑 | 总是 | 打开详情面板 |
| 拆解 | status ≠ completed/cancelled | 弹窗 → splitEdge |
| 删除 | 总是 | deleteEdge |
| 标记完成 | C9 + 状态机合法 | updateEdgeStatus → completed |
| 取消 | 状态机合法 | updateEdgeStatus → cancelled |

### 6.3 Me 节点右键

| 菜单项 | 动作 |
|--------|------|
| 编辑名称 | 修改 Me.name |
| 添加目标 | createGoal（默认 Me→新目标连线） |

## 9. 与 v0.2 的差异

| 变化点 | v0.2 | v0.3-ui |
|--------|------|---------|
| 文档范围 | 逻辑+UI 混合 | 纯 UI 交互 |
