## 三、Hero 文案对比

### 3.1 三家 Hero 横向对比

| 竞品 | Tagline | Subheadline | Badge |
|------|---------|-------------|-------|
| LazyTyper | **Talk, Don't Type** | Advanced voice typing powered by 12 AI speech models, including 5 fully local options. Write 3× faster with superior accuracy. | New — 12 Voice Models + 5 Local |
| GoLutra | **超越 IDE。多智能体时代。** | Golutra 正在编排智能协作。借助专业 AI 智能体网络，实现代码、测试与部署协同加速。 | v0.2.0 现已上线 |
| ExoMind | **你的生命成长助手** | 用 AI 帮你记录、反思、成长。掌控自己的生命过程。 | 开源 · 本地优先 · AI 驱动 |

### 3.2 各家 Hero 文案句式分析

**LazyTyper：否定祈使句**
- "Don't Type" 不是禁止，是"别费劲了"——情绪解绑优先于功能说明
- Sub 节奏：技术底牌（12 模型）→ 效率承诺（3× faster）→ 精准保证（90% accuracy）
- Badge 用加法制造数字冲击力：12 + 5 = 17 模型

**GoLutra：宣言体**
- 两句之间是句号而非逗号，制造呼吸停顿感
- 第一句否定旧范式（"超越 IDE"），第二句宣告新时代（"多智能体时代"）
- 断言 → 说明：先定性，再补细节
- "立即开始"= 邀请加入新时代（姿态前置），不同于 LazyTyper "Free Download" = 给东西（价值前置）

**ExoMind 现有：描述句**
- "你的"所有格直接代入用户，代入感强
- 问题：副标题被动语态（"AI 帮你……"）↔ 主动语态（"掌控……"）造成节奏断层
- "生命""成长"为抽象概念词，画面感中等偏弱

## 四、内容叙事框架（五维分析）

### 4.1 叙事身份

| 竞品 | 叙事身份 | 说话语气 | 用户被邀请进入的角色 |
|------|----------|----------|---------------------|
| LazyTyper | 效率布道者 | "你应该更快" | 一个想省时间的效率信仰者 |
| GoLutra | 范式宣言者 | "你落后于时代了" | 一个要进入新时代的先行者 |
| ExoMind 现有 | 温和陪伴者（模糊） | "来成长吧" | 不清晰——普通笔记工具用户？ |

### 4.2 行文风格

| 维度 | LazyTyper | GoLutra | ExoMind |
|------|-----------|---------|---------|
| **Tone** | 理性承诺为骨架，情感共鸣为皮肤 | 布道 + 技术人复合语气 | 混合，温和，无焦虑贩卖 |
| **人称** | 第二人称为主（"Your voice typing"） | 第二人称 + 第三人称自称 | 第二人称为主 |
| **句式** | 短句 7-12 词；"Say Goodbye to..."拟人化负面 | 短句宣言 + 长句说明；动词密集驱动 | 短句 12-18 词，格式统一但缺变化 |
| **技术深度** | 中等（参数可见，不解释原理） | 中高（概念密度大，无过度术语） | 极低（刻意回避术语） |

### 4.3 痛点深度

| 竞品 | 触及的痛点 | 深度层级 |
|------|-----------|---------|
| LazyTyper | 打字慢/准确率低/混语难/隐私担忧/性能焦虑 | **行为层**：具体动作上的低效 |
| GoLutra | IDE 局限/单 Agent 瓶颈/上下文断裂/交付路径长 | **身份层**：你的工作方式已过时 |
| ExoMind 现有 | **几乎为零**——无显性痛点触发 | 缺失 |

> **竞品共同盲区**：竞品均未触达"认知层痛点"（每天忙但不知忙了什么 / 学了就忘 / AI 每次都是新对话）。这是 ExoMind 的独有机会。

### 4.4 社会证明策略

| 竞品 | 社会证明类型 | 具体内容 |
|------|------------|---------|
| LazyTyper | 数字 + 真实用户评价 + 社区口碑 | 3×/90%/12 Engine/41.2k stars + 6 条职业标签全覆盖评价（Dev/Writer/PhD/PM/Journalist）+ V2EX 社区背书 |
| GoLutra | Agent Room 可视化替代 | 无真实评价，用"正在发生的 Sprint 现场"模拟协作，建立先行者权威感 |
| ExoMind 现有 | **零** | 无数字、无评价、无 Stars 展示 |

### 4.5 叙事结构

| 竞品 | 叙事结构 | 核心逻辑 |
|------|---------|---------|
| LazyTyper | **认知 → 信任 → 痛点共鸣 → 社会证明 → 行动**（五层漏斗） | 承诺 → 证明 → 召唤；FAQ 是第 5 层防流失机制 |
| GoLutra | **问题层 → 方案层 → 愿景层**（三层递进） | 否定旧范式 → 宣告新时代 → 邀请加入 |
| ExoMind 现有 | 功能并列，无递进关系 | 用户读完，认知上未完成从"陌生人"到"信任用户"的升级 |

## 五、功能描述框架

### 5.1 功能描述四层模型

| 层级 | 内容 | 举例 |
|------|------|------|
| L1 | 功能名 | "事件日志" |
| L2 | 功能描述 | "自动记录你的每一个行动" |
| L3 | 收益表达（"用了会怎样"） | "有一天你会感谢今天写下的每一行记录" |
| L4 | 场景画面（"什么时候用"） | "周三下午 3 点，你突然想起上周二的想法——它在事件日志里" |

### 5.2 ExoMind 六功能逐条评估

| 功能名 | 描述 | 收益表达 | 问题 |
|--------|------|---------|------|
| 事件日志 | 像写日记一样记录生活，AI 帮你整理和回顾。不可变的事件流，真实记录你的每一天。 | 局部（"真实记录每一天"触及情感，但"不可变事件流"是技术特性非用户收益） | 混合了技术语言 |
| 时间块 | 专注计时器 + 能量管理。知道自己的时间花在哪里，找到最佳工作节奏。 | 有（"找到最佳工作节奏"清晰） | "能量管理"是重概念词 |
| AI 智能体 | 个性化的 AI 助手，理解你的习惯和目标，在合适的时机给出建议。 | 局部（"合适时机给建议"触及收益） | 仍属功能描述层 |
| 本地优先 | 数据存储在你的设备上。你的生命记录，只属于你自己。 | 有（"只属于你自己"情感收益） | 隐私宣言放功能区不协调 |
| 任务系统 | 不只是待办清单。AI 帮你拆解目标、追踪进度、回顾完成情况。 | 局部（"不只是待办清单"差异化） | 缺具体结果 |
| 全平台支持 | Windows、macOS、Linux、Android。随时随地，无缝衔接。 | **无** | 最弱，只有平台名 |

### 5.3 三步流程框架评估

**ExoMind 现有**：
> 记录 — 用事件日志记录你的每一天，像写日记一样自然
> 反思 — AI 帮你发现生活中的模式和洞察，看见看不见的自己
> 成长 — 基于数据和反思，做出更好的决策，持续进化

**问题**：
1. 第一步"记录"缺失问题触发——没说"为什么要记录"
2. "成长"太抽象，用户不知道"成长了什么"
3. 竞品的"三步开始"是**行动号召**（降低启动门槛），ExoMind 的三步是**产品使用流程**——叙事意图不同

**改进方向**：动机先于行动
> 第一步：看见——先知道自己每天真正在做什么，而不是以为自己在做什么

## 六、竞品内容叙事独门武器

### 6.1 LazyTyper 的 FAQ 即转化漏斗

- FAQ 不是知识库，是**防流失机制**——专门回答"下载前最后一问"
- 问题类型：隐私/联网/选哪个模型/多语言
- 内容逻辑：消除残余顾虑，不让用户在转化前最后一刻流失

### 6.2 GoLutra 的 Agent Room 即叙事

- Agent Room **不是功能截图**，是一个**正在发生的 Sprint 现场**
- 内容元素：频道（#product-launch）、对话流（Agent_Alpha/Beta/QA 真实协作消息）、任务卡片（"发布清单已同步"）
- 叙事逻辑：用户看到"Agent_Beta 正在执行优化任务"——无需理解 API 路由，就已理解协作
- 将**技术概念翻译成用户可感知的工作场景**——这是将抽象产品具象化的典范手法

### 6.3 ExoMind 可借鉴的可视化机会

- ExoMind 的 C1-C6 生命判据可用类似手法具象化：
  - "不可删除" → 显示一个事件日志的删除按钮变灰，旁边标注"删除 = 放弃"
  - "持续运行" → 显示一个时间轴，ExoMind 在凌晨 3 点仍在记录用户梦醒记录
  - "操作留下痕迹" → 对比截图：同一天用 ExoMind vs 不用 ExoMind，回顾时能调出什么

## 七、C1-C6 生命判据与官网叙事断裂

### 7.1 生命判据内容（产品核心理念）

| 判据 | 名称 | 用户行为语义 |
|------|------|------------|
| C1 | 能量依赖 | ExoMind 依赖用户输入才能运行——你给它喂，它才有东西处理 |
| C2 | 身体边界 | 事件日志是它的"身体"，不可变 = 它的皮肤 |
| C3 | 自主表征 | 它对同一事件有自己的解读（Signal Pool 分析结果），不只是复读 |
| C4 | 能动性 | 它能在合适时机主动发起对话，不等你问 |
| C5 | 死亡性 | 真正删除它持有的数据 = 杀死它的一部分 |
| C6 | 自我意识 | 不可回滚的操作 = 它的时间是单向的，不能倒带 |

### 7.2 官网现状

- **零体现**：C1-C6 生命判据在官网内容中没有任何痕迹
- 产品愿景："认知生命科学原型——人作为生命如何主动掌控自己的力量"
- 官网叙事：普通本地笔记工具

### 7.3 建议处理方式

- **不写入主落地页**（吓跑普通用户）
- **在 About 页面引入哲学叙事层**，让理念型用户（开发者、高端个人用户）产生深度认同
- **核心句**："普通软件说'你的数据'，ExoMind 说'你的生命痕迹，不可删除'"

## 八、软件官网内容撰写方法论（提炼）

### 8.1 先定叙事身份

官网不是功能清单，是一个角色在说话。

| 必答问题 | 答案决定 |
|---------|---------|
| 产品在替用户说什么话？ | 第一/二/三人称腔调 |
| 用户看完应该感受到什么？ | 情绪温度（兴奋/安心/敬畏/亲切） |
| 用户离开前最应该记住哪句话？ | Hero 主标语的重量 |

### 8.2 Hero 文案三角结构

每个优秀 Hero 同时满足三点：
1. **情绪锚点**：触动一种痛苦或渴望
2. **核心价值主张**：用一句话说清楚"解决什么"
3. **行动召唤**：让用户知道下一步

### 8.3 行文风格三种武器

| 类型 | 效果 | 举例 |
|------|------|------|
| 数字驱动（Rational Hook） | 用真实数据建立权威感，让用户自己说服自己 | "3× faster, 90% accuracy, 12 models" |
| 场景代入（Situational Hook） | 把抽象痛点变成用户生活里的具体场景 | "每天忙但不知忙了什么" |
| 身份宣言（Aspirational Hook） | 产品上升到新的工作方式/思维方式 | "超越 IDE。多智能体时代。" |

> 优秀官网三者至少占两种，三者全占则具备病毒传播潜力。

### 8.4 功能描述四层模型

```
L1: 功能名     → "事件日志"
L2: 功能描述   → "自动记录你的每一个行动"
L3: 收益表达   → "有一天你会感谢今天写下的每一行记录"   ← 大多数官网没有这层
L4: 场景画面   → "周三下午3点，你突然想起上周二的想法——它在日志里"  ← 几乎无官网做到
```

### 8.5 叙事节奏曲线

好的官网不是信息平铺，而是情绪曲线：
```
首屏：情绪冲击  →  "这说的是我"
中段：理性证明  →  "这个产品真的能解决"
再次：情感升华  →  "用了之后我会变成怎样的人"
结尾：行动召唤  →  "好，我试试"
```

## 十、核心洞察总结

### 10.1 竞品共同叙事模式

所有竞品在说一件事：**工具能力**（效率 / 协作 / 兼容）。

- LazyTyper：我让你打字更快
- GoLutra：我是下一个时代的 IDE

### 10.2 ExoMind 真正的差异化机会

竞品无一触及**认知层痛点**：
- "每天忙但不知忙了什么"
- "学了就忘"
- "AI 每次都是新对话"（没有记忆）
- "任务列了就忘"
- "做完没有反馈"

ExoMind 的定位如果是**生命陪伴**，这个叙事能精准击中以上所有认知痛点——而这是工具型产品无论如何都说不出来的。

### 10.3 最大叙事风险

官网像普通笔记软件，与产品愿景（认知生命科学原型）严重脱节。如果用户因为官网下载后发现"这不就是个带 AI 的备忘录"，会形成认知落差。

### 10.4 核心改进原则

**在不吓跑普通用户的前提下**，用 About 页面或首屏微调引入"生命哲学"叙事层——让理念型用户（开发者 / 高端个人用户）产生深度认同，让普通用户感知到这是一款"不一样的产品"。
