# Task DAG 联合搜索 / 聚焦系列手测样例

## 目标

为 `/tasks/dag` 提供一组可重复执行的 RT 样例任务，专门用于手测：

- 文本搜索 + 标签搜索的联合 `AND`
- 标签内部 `and/or` 切换
- `过滤` 开关对统一搜索结果的硬隐藏
- `聚焦系列` 在两个不连通系列之间的弱化表现
- `描述` 搜索与标签搜索的联合命中

## Seed 脚本

```bash
bun scripts/dev/seed-task-dag-search-focus-examples.ts --host 127.0.0.1 --port 9124 --user-id anonymous
```

也可以直接传完整 RT 地址：

```bash
bun scripts/dev/seed-task-dag-search-focus-examples.ts --base-url http://127.0.0.1:9124 --user-id anonymous
```

脚本特性：

- 只调用 RT HTTP `/tasks/replication/upsert`
- 使用固定 task id，可重复执行，不会不断堆重复样例
- 只会写入带 `sample` 标签的样例任务，不触碰同 scope 下其他已有任务

## 复杂依赖补充样例

为验证更真实的 DAG 结构，当前 RT `9124` 还额外补了一组复杂依赖样例：

- 菱形分合
  - `sample-q-diamond-a`
  - `sample-q-diamond-b`
  - `sample-q-diamond-c`
  - `sample-q-diamond-d`
  - 结构：`A -> (B, C) -> D`
- 双层分合
  - `sample-q-double-a` 到 `sample-q-double-g`
  - 结构：`A -> (B, C) -> D -> (E, F) -> G`
- 跨桥系列
  - `sample-q-bridge-a`
  - `sample-q-bridge-b`
  - `sample-q-bridge-c`
  - 结构：桥接已有 `sample-q-main-*` 与 `sample-q-side-*`，用于验证多系列聚焦、过滤后聚焦、以及跨系列上下文保持

这些样例全部通过 RT `/tasks/replication/upsert` 写入 `anonymous` scope，可重复 upsert。

长标题边界样例：

- `sample-q-long-title-boundary`
  - 依赖：`sample-q-diamond-d`
  - 用途：验证长标题优先展示、弱语义标签先退场、以及悬浮/选中时的临时展开

## 推荐手测动作

1. 文本输入 `Batch Q`，再点标签 `dag`
   - 预期：两条 DAG 系列同时命中；文本-only、tag-only、RT 样例都弱化

2. 在上一步基础上开启 `过滤`
   - 预期：只剩命中 `Batch Q` + `dag` 的节点；非命中节点硬隐藏

3. 在上一步基础上右键 `样例/DAG 搜索主线：Batch Q 聚焦系列主链`，点击 `聚焦此系列`
   - 预期：主线系列保持正常；旁系 `X/Y` 弱化；已经被过滤隐藏的节点不会被带回

4. 清空搜索；选择标签 `dag` + `focus`
   - 预期：默认标签内部 `and` 只命中带 `dag` 和 `focus` 的节点

5. 在上一步点击标签匹配模式切到 `or`
   - 预期：命中范围扩大到仅带 `dag` 或仅带 `focus` 的相关样例

6. 文本输入 `Markdown`，开启 `描述`，再点标签 `frontend`
   - 预期：只命中 `样例/前端节点`

7. 清空搜索，定位 `sample-q-diamond-*`
   - 预期：能看到标准菱形 `A -> (B, C) -> D`
   - 重点观察：`B/C` 不应被挤成固定死板方块；在同一 `160×160` 占位区中，短内容卡片应更紧凑并居中

8. 再定位 `sample-q-double-*`
   - 预期：能看到双层分合 `A -> (B, C) -> D -> (E, F) -> G`
   - 重点观察：两次分合后的布局仍保持统一间距和清晰层次

9. 清空搜索后，右键 `sample-q-bridge-b` 或 `sample-q-bridge-c` 使用聚焦系列
   - 预期：桥接链与它在当前可见图中的连通节点一并保留正常，其余系列弱化或按过滤条件隐藏
   - 重点观察：过滤后再聚焦时，不应把已被隐藏的其他节点“带回来”

7. 清空搜索后，定位 `样例/Q 菱形 A 起点` 到 `样例/Q 菱形 D 汇合终点`
   - 预期：能清楚看到 `A → (B, C) → D` 的菱形分合关系
   - 用途：验证“分→合”基础拓扑、选点、聚焦和布局是否稳定

8. 对 `样例/Q 菱形 D 汇合终点` 执行“聚焦此系列”
   - 预期：菱形四节点保持正常；不在该系列内的其他样例弱化或隐藏，取决于当前搜索/聚焦模式

9. 观察 `样例/Q 交织 A 起点` 到 `样例/Q 交织 F 最终汇合`
   - 预期：能看到一条比菱形更复杂的“分支 + 中途汇合 + 再汇合”结构
   - 用途：验证布局在多次分合下仍不塌缩，且聚焦系列并集语义保持正确

10. 观察 `样例/Q 多入口 A`、`样例/Q 多入口 B` 到 `样例/Q 多入口 E 最终汇合`
   - 预期：能看到两个独立入口汇入同一终点，不会被误判成单链
   - 用途：验证多入口场景下的浏览、搜索和后续区间收缩边界判断

11. 搜索或定位 `sample-q-long-title-boundary`
   - 预期：基础态优先保住标题，`聚焦锚点` 等弱语义标签在空间紧张时可先退场
   - 再操作：选中该节点
   - 预期：卡片围绕原中心点展开，标题变完整，弱语义标签恢复显示，布局不重排
