## 七、问题与优化

### 遇到的问题

| 问题 | 原因 | 解决方案 | 优化建议 |
|------|------|----------|----------|
| RecordPage 状态同步 | VoiceMessageInput 内部管理 inputValue | 使用 useRef + onVoiceResult 回调 | 组件设计时提前考虑外部状态同步 |
| Button 未定义 | ChatPage 移除导入后仍使用 Button | 添加缺失的导入 | 重构时使用 IDE 重构功能替代手动修改 |
| Playwright 检测 | 组件编译后无 HTML 标记 | 通过 input 元素存在性验证 | 验证组件时检查功能而非 DOM 标记 |

### 有价值发现

1. **两步走战略有效**
   - 第一步：路由适配（快速验证）
   - 第二步：组件抽象（复用提升）
   - 每步独立提交，便于回滚

2. **语音输入组件设计**
   - Props 最小化设计
   - 支持 ASR 适配器注入
   - onVoiceResult 回调支持标签同步

3. **验证流程**
   - 先构建验证，再功能验证
   - Playwright 比手动测试更可靠
