# Preview v0.5.0

预览版
v0.5.0
2026/07/01

## 给使用者看的摘要

0.5 是外心精简路线的起点，不是终点。这一版我们删了主页、实时语音、工作台、反馈 / 遥测 / 法律支持 / 赞助入口与 MOSS 引擎，让外心只留下你最常用的几个东西；同时修了几处用着就会撞上的卡顿和配置失效。

日常推荐装的是 0.5 系列里的稳定号（0.5.[max]），不是 0.5.0；想早期试用 0.5.0-preview 请直接安装，问题请帮我们回流。

## 我们怎么发版 / How We Version

外心当前在 0.x 阶段：小版本号变更允许大重构，没有"攒够一波再发"。

### 版本节奏

从 0.5 开始，**精简、重构、bug 维护** 当作一个长期主题持续做下去；后续每完成一次这类变更，我们就迭代一个小版本号直接发出去。
理由是想避免"攒一波再发"导致无限拖延，让精简路径上的每一步都能被立即使用并验证。

### 哪一版才是稳定版

用户真正可用的「稳定版本」并不是 0.x.0，而是同一系列里的 **0.x.[max]**：
- **0.x.0** 是「系列开启」的预览版，适合早期试用和问题回流（带 dogfooding 痕迹）。
- **0.x.[max]** 是日常推荐装的那一个，经几轮迭代补丁后才升到。

这套规则同时解决两件事：保留后续维护与补丁的空间，又避免无限拖延。1.0 之前都按这套节奏。

**术语小抄**：对外（用户与官网）我们用 `0.x.[max]` 指稳定号、`0.x.0` 指系列首预览；对内 Git tag 永远用 `v0.x.y`，preview release body 标 `-preview`。

## What Changed / 本次变化

删除

- 我们删了「个人主页」、「实时语音」、「工作台」、「反馈 / 遥测 / 报告问题 / 法律支持 / 赞助」这些分散注意力的入口，以及原 MOSS 语音引擎的整套接入。主语音按钮已切到火山。外心其余你最常用的几个东西——专注、当下、时间块反馈、录音浮窗、内置引擎、任务流、事件日志、Agent 协作、设备网络、官网发布——全部保留。

优化

- 主语音按钮从原 MOSS 引擎切到火山；旧接入代码、配置、设置项全部清掉，火山需要在设置页重新填一次凭证。
- 我们让信号日志库稳定在 1 万行内，止住后台磁盘持续高占用，长时间挂着电脑也不会越用越慢。
- 我们集中调优了所有数据库连接；只读库切换失败时会安全降级，不让性能优化把启动路径搞挂。

修复

- 我们修了事件日志记录页首屏加载十几秒、向上翻页卡死的故障；现在打开记录页毫秒级出，往上翻几千条也不会卡。
- 我们修了 focus 模式「软结束」配置不生效的 bug：你设的「soft」现在会真正生效，跨时间块的状态不再混到上一个人头上。

文档

- 我们补充了 macOS 自签安装说明与首次启动引导；下载页同步更新（详细步骤见下载页说明）。

## 安装与使用 / Install & Run

> ⚠️ **macOS 包暂未签名**（无 Apple Developer 账号）。首次打开提示「已损坏」是 **Gatekeeper 拦截，不是文件真的损坏**。完整说明见 **[macOS 安装说明](https://github.com/exomind-team/exomind/blob/dev/docs/macos-install.md)**。

**Windows** — 下载 `ExoMind-0.5.0-windows-x64-setup.exe`（或 `.msi`）双击安装。若 SmartScreen 拦截，点「更多信息 → 仍要运行」。

**macOS（Apple Silicon / M1–M4）** — 安装 `ExoMind-0.5.0-macos-aarch64.dmg`。若提示「ExoMind 已损坏」，在终端执行以下命令做一次 **ad-hoc 自签**（免费、无需 Apple 账号；arm64 强制要求带签名）：

```bash
sudo codesign --force --deep --sign - "/Applications/ExoMind.app"
sudo xattr -cr "/Applications/ExoMind.app"
open "/Applications/ExoMind.app"
```

> **Intel Mac**：本预览版未出 x86_64 DMG；请用上述 Apple Silicon 包在 Rosetta 下启动（首次右键 `ExoMind.app` →「打开」即可），或在 Apple Silicon 机器上自取 aarch64 包后通过 AirDrop / 文件共享到 Intel 机（不能直接运行为原生二进制）。完整的 Intel Mac 路线会在 v0.5.[max] 稳定号里补齐。

**Linux** — `.AppImage`：`chmod +x ExoMind-0.5.0-linux-x64.AppImage && ./ExoMind-0.5.0-linux-x64.AppImage`；或 `.deb`：`sudo dpkg -i ExoMind-0.5.0-linux-x64.deb`。

**Android** — 安装 `ExoMind-0.5.0-android-arm64.apk`（绝大多数手机）；旧设备 / 模拟器用 `-x86`。需在系统里允许「未知来源 / 安装未知应用」。
