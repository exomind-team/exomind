# ExoMind MVP 架构设计

> 最小验证版：记录生命中的每一个事件

## 概述

ExoMind MVP 是一个命令行应用，用于追踪和记录日常生活中的事件与时间块。它是 ExoMind 系统的最小验证原型，验证了事件驱动的生命日志这一核心概念。

## 核心类结构

```
│  - id: UUID          唯一标识                                        │
│  - name: 块名称                                                      │
│  - note: 总结/反思                                                   │
│  - startId: 开始事件ID                                               │
│  - endId: 结束事件ID                                                 │
│  - tags: 标签                                                        │

                              ↕ 管理

```

## PlannedTimeBlock（计划时间块）

```
┌─────────────────────────────────────────────────────────────────────┐
│                  PlannedTimeBlock (计划时间块)                       │
│  用于追踪"已开始但未结束"的时间块                                     │
│  - startId: 开始事件ID                                               │
│  - name: 块名称                                                      │
│  - tags: 标签                                                        │
│                                                                       │
│  这是 TimeBlock 的"未完成态"，当用户输入"开始X"时创建，              │
│  输入"结束"后转化为完整的 TimeBlock。                                │
└─────────────────────────────────────────────────────────────────────┘
```

## 数据流

```
┌─────────────────────────────────────────────────────────────────────┐
│                         用户交互流程                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  开始时间块                                                         │
│  ┌───────────────────────────────────────────────────────────────┐ │
│  │ 输入: "开始写代码"                                             │ │
│  │ → Event (block_start 标签)                                    │ │
│  │ → PlannedTimeBlock (活跃状态)                                 │ │
│  └───────────────────────────────────────────────────────────────┘ │
│                              ↓                                      │
│  记录事件                                                           │
│  ┌───────────────────────────────────────────────────────────────┐ │
│  │ 输入: 任意文本                                                 │ │
│  │ → Event (普通事件)                                            │ │
│  └───────────────────────────────────────────────────────────────┘ │
│                              ↓                                      │
│  结束时间块                                                         │
│  ┌───────────────────────────────────────────────────────────────┐ │
│  │ 输入: "结束"                                                  │ │
│  │ → Event (block_end 标签)                                      │ │
│  │ → TimeBlock (关联开始/结束事件)                               │ │
│  │ → 提示输入总结/反思                                           │ │
│  └───────────────────────────────────────────────────────────────┘ │
│                              ↓                                      │
│  数据持久化                                                         │
│  ┌───────────────────────────────────────────────────────────────┐ │
│  │ exit / 错误时                                                  │ │
│  │ → toJSON() 序列化                                             │ │
│  │ → 写入 data/exomind.json                                      │ │
│  └───────────────────────────────────────────────────────────────┘ │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 启动流程

```
1. 读取 data/exomind.json
2. loadJSON() 恢复所有事件和时间块
3. 如果有活跃的 PlannedTimeBlock，恢复状态
4. 打印欢迎信息和当前状态
5. 进入 readline 主循环
6. 用户输入 → handleInput() → 处理 → 保存
7. 退出时自动保存
```

## 核心设计决策

### 1. 事件驱动

- 所有数据都是 Event 的集合
- TimeBlock 是 Event 的"聚合"视图
- 便于查询、过滤、统计

### 2. 离线优先

- 所有数据本地存储（JSON 文件）
- 启动时加载，退出时保存
- 无网络依赖

### 3. 时间块模式

- "开始X" → 创建时间块上下文
- 期间所有事件都属于该时间块
- "结束" → 完成时间块，输入反思

## 与完整版的关系

MVP 验证了以下核心概念：

| MVP 概念 | 完整版对应 | 说明 |
|----------|-----------|------|
| Event | Event | 基础不变 |
| TimeBlock | TimeBlock | 基础不变 |
| ExoMindLogs | SignalPool | 本地存储 → 事件总线 |
| CLI | React UI | 终端 → Web UI |
| JSON 文件 | FileStorage + P2P | 本地 → 分布式 |

MVP 是 ExoMind 的"种子"，完整版在此基础上增加了：
- 消息路由与分流
- P2P 多设备同步
- WebSocket 通信
- Agent 任务系统
