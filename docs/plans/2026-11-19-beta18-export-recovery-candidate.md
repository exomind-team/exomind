# Beta18：导出中断恢复候选

## 本轮目标

把已提交的 `449d0335` 原件导出恢复切片构建为可验证候选。该源码的 GitHub Source
Contracts run `44538506512` 已成功；本机纯 journal 9 项、导出 29 项、完整 TypeScript、
全量 Beta 83 文件／591 项与 Windows Native `cargo check` 已通过。

场景是：Android 系统选择器期间外心进程被回收，目的文档可能已创建，旧内存回调与
前端任务消失。新候选持久记录任务，重启后显示未确认／中断，保留原件并允许新请求
重新选址。它不自动接续旧 URI。完整合同见
[导出恢复](../development/beta-original-export-recovery.md)，失败原证据见
[Beta17](2026-11-19-beta17-physical-original-diagnostics.md)。
