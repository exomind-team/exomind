# Step 2

你现在处理“建立或校验 draft PR + 上锁”。

执行要求：

1. 检查是否已经满足 draft PR 四个门槛：
   - 已创建分支
   - 已有首个提交
   - draft PR 已存在
   - PR body 已写好
2. 若 draft PR 不存在，先创建 draft PR。
3. PR body 使用 `[Codex Worker]` 前缀，并包含 `refs/closes/fixes #xxx`。
4. 拿到 PR 号后，立即上锁：
   - `npx tsx Scripts/dev/worker-agent/index.ts lock acquire --pr <PR_NUMBER> --agent-id <AGENT_ID> --timeout-minutes 60`
   - 若环境提供 bun，也可使用：`bun Scripts/dev/worker-agent/index.ts lock acquire --pr <PR_NUMBER> --agent-id <AGENT_ID> --timeout-minutes 60`

完成条件：

- 当前 PR 已存在且已上锁。
