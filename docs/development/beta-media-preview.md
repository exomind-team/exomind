# Beta 本机音视频预览

这是冻结 Beta16 后的源码增量，最终候选与原件读取仍按
[持续完成计划](../plans/2026-11-19-beta16-frozen-and-beta-completion.md)验收。

`OriginalDownloads` 只为本机可读原件提供预览，通过既有下载读取接口校验长度和 hash。
显式点开后才读取，预览最多 16 MiB；格式、扩展名、浏览器 codec 能力和读取预算分别检查。
播放列表及外部引用不跟随，未知格式和超限保留系统打开／下载路径，不自动执行附件。

预览使用本机 Blob URL 和自定义播放、定位、音量控制，不自动播放或显示系统媒体控件。
请求播放、实际开始、缓冲、暂停、结束和失败分别反馈；旧播放请求的失败不能覆盖用户后来
的暂停或新请求。未知时长不填零；不可定位时说明原因。关闭、隐藏或换来源释放本预览的
decoder／URL，旧读取不得重新打开新来源。录音 session 属于独立设备所有者，不能随此
预览的显隐一起停止。

界面复用共享 Dialog／Button，触摸控件和关闭入口有足够点击范围，焦点回到触发入口。
共享 Dialog 的关闭按钮样式通过语义 slot 定制；播放器无需依赖最后一个子元素的 DOM 位置。
音频仅保留一处文件标题，不为重复文件名增加空卡片。

相关媒体策略与 UI 39 项回归、定向严格 TypeScript 检查通过。Windows 还在隔离的冻结
Beta16 Native WebView2 中渲染新组件，以静音合成 WAV 实测解码、播放时钟、暂停、定位、
音量、键盘／模拟触摸关闭、返回焦点、保留草稿和 URL 回收，共 7 项检查通过并确认实例退出。
场景含桌面深色、窄屏明暗色、短横屏，均无系统滚动条及横向溢出。
这批是新前端组件与冻结 Native 的兼容验证，未用它证明新候选原件链路、实际扬声器、
物理 Android 或最终人工审美通过。
