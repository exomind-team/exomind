# 第 2 步

> 仅供参考：该文件仅作为流程参考，不再作为循环输入提示词。实际入口是 `docs/worker-agent/prompts/main.md`。

你现在处理“建立或校验草稿 PR + 上锁”。

执行要求：

1. 检查是否已经满足草稿 PR 的四个门槛：
   - 已创建分支
   - 已有首个提交
   - 草稿 PR 已存在
   - PR 正文已写好
2. 若草稿 PR 不存在，先创建草稿 PR。
3. PR 正文使用 `[Codex Worker]` 前缀，并包含 `refs/closes/fixes #xxx`。
4. 拿到 PR 号后，立即上锁：
   - `npx tsx Scripts/dev/worker-agent/index.ts lock acquire --pr <PR_NUMBER> --agent-id <AGENT_ID> --timeout-minutes 60`
   - 若环境提供 bun，也可使用：`bun Scripts/dev/worker-agent/index.ts lock acquire --pr <PR_NUMBER> --agent-id <AGENT_ID> --timeout-minutes 60`

完成条件：

- 当前 PR 已存在且已上锁。
