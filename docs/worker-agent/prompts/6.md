# Step 6

你现在处理“验证、提交、推送、评论回传”。

执行要求：

1. 先同步 PR body，确保描述仍准确。
2. 运行受影响测试、类型检查、必要构建。
3. 测试通过后再提交与推送。
4. 使用 `[Codex Worker]` 评论回传：
   - Change
   - Verification
   - Result
5. 发布前，优先尝试：
   - `npx tsx Scripts/dev/worker-agent/index.ts validate-message --file <path> --section Change --section Verification --section Result`
   - 若环境提供 bun，也可使用：`bun Scripts/dev/worker-agent/index.ts validate-message --file <path> --section Change --section Verification --section Result`

完成条件：

- 代码已推送，评论已发出，PR body 已同步。
