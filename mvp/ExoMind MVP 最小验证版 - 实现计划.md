## 核心数据结构

```typescript
// Event 事件
interface Event {
  id: string              // UUID
  timestamp: number       // Unix ms
  type: 'note' | 'block_start' | 'block_end' | 'state_check'
  content: string
  blockId?: string        // 关联的时间块ID
}

// TimeBlock 时间块
interface TimeBlock {
  id: string              // UUID
  startId: string         // 开始事件ID
  endId?: string          // 结束事件ID（未关闭时为空）
  name: string            // 时间块名称
  startTime: number
  endTime?: number
}

// 存储结构
interface Storage {
  events: Event[]
  timeBlocks: TimeBlock[]
  activeBlockId?: string  // 当前活跃时间块ID
}
```

## 关键行为（完整版）

### 关键词触发规则

| 输入 | 动作 |
|------|------|
| `开始xxx` | type='block_start', 创建新 TimeBlock, name='xxx' |
| `结束` | type='block_end', 关闭当前 activeBlockId |
| `今天好累` | type='note', 普通记录 |
| `exit`/`quit`/`q` | 保存 data/exomind.json, 退出 |
| 空行 | 跳过 |

### 触发规则

- 必须以"开始"开头才算时间块开始（如"我今天开始写论文"不算）
- 结束时不匹配名称，输入"结束"即可关闭当前块
- 名称解析：去掉"开始"后，剩余全部作为时间块名称

### 文件处理

- 文件不存在时自动创建空的 Storage，提示用户
- 文件存在但读取失败（权限问题）：询问用户退出还是重置
- JSON 格式错误但可修复：提示用户，提供"重新加载"选项
- JSON 文件格式化存储（JSON.stringify(data, null, 2)）
- 数据文件路径：`./data/exomind.json`
- ID 生成：`crypto.randomUUID()` Node.js 原生 API

### 错误处理

- JSON 文件损坏或读写错误时：
  - 打印错误信息和详细位置
  - 询问用户：退出还是重置？
  - 若重置，必须输入 "RESET" 大写全拼确认
  - 重置前提醒用户"原先数据可能损失！"

### 并发处理

- 有活跃块时用户输入"开始xxx"：
  - 提示用户先结束当前块
  - 询问是否帮您结束当前块？
  - 输入 `y` 确认，输入其他取消

### 时间块异常

- 超过 4 小时未结束的时间块：
  - 在块信息旁标记 🔴 已进行 X 小时
  - 在输入新事件时提醒

### REPL 界面

**启动时：**

1. 欢迎语：`"ExoMind v1.0 - 外心 MVP - 记录生命中的每一个事件 (Ctrl+D 发送，exit 退出)"`
2. 数据加载日志
3. 如果有数据：打印当前块 + 最近10个时间块（旧到新）
4. 如果无数据：仅欢迎语后直接提示符

**事件展示格式：**

- 时间块之间用 `---` 分隔
- 每个块信息（中档格式）：

  ```
  🔷 [块名] | 开始时间: 2026-02-07 14:30 | 已记录 5 条 | 持续 65 分钟
  ```

- 已结束块：块信息后加一行 `✅ 已完成`
- 超过4小时：旁边标记 🔴 已进行 X 小时
- 块内事件（包含首尾）：
  - 4个空格缩进
  - 格式：`📝/🔷/🔴 时间 事件内容`
  - 时间渐进披露：与当前时间比较，相同年省略年份，相同日省略日期

**提示符：**

- 有活跃块：`[块名] >`
- 无活跃块：`>`

**输入：**

- Ctrl+D 发送
- 提示符中提示

### 立即反馈格式

- 成功：绿色
- 错误：红色
- 块信息：蓝色
- 格式：

  ```
  📝 事件已记录
  ID: xxx-xxx
  时间: 2026-02-07 14:30:05
  内容: xxx
  ```

### 事件图标

| 类型 | 图标 |
|------|------|
| 普通事件 | 📝 |
| 开始事件 | 🔷 |
| 结束事件 | 🔴 |

### ANSI 颜色

- 成功：32 绿色
- 错误：31 红色
- 块信息：34 蓝色
- 警告：33 黄色

## 验证步骤

1. `bun main.ts` 启动 REPL
2. 输入 `开始写代码` → 创建事件 + 时间块，输出反馈
3. 输入 `刚才解决了登录bug` → 创建普通事件，输出反馈
4. 输入 `结束` → 关闭时间块，输出反馈
5. 输入 `exit` → 保存并退出
6. 查看 `data/exomind.json` 验证数据正确
