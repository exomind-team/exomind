### 1.2 架构设计决策

```
L1-Network: HTTP/WebSocket/P2P 抽象层
L2-Storage: SQLite 存储抽象（Interface-based）
L3-Sync: 暂移除（单 Actor 场景不需要）
L4-Actor: 暂移除（单 Actor 场景不需要）
L5-Signals: 信号池（数据获取与查询分离）
L6-Agent: 业务逻辑层 + Resource Fetcher
L7-UI: 前端展示层
```

### 1.3 关键设计

**Resource Fetcher 模块**：
- 统一接口：`fetch(input) → Promise<output>`
- 三种实现：PlaywrightFetcher / HttpFetcher / ApiFetcher
- 支持 MiniMax API、网页抓取、文件下载

**能源感知用户故事**：
- R08: Agent 自主查询真实能源消耗
- R09: 能量池状态可视化
