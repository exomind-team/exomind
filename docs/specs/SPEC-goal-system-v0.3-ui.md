## 0. UI 设计原则

### 0.1 取消 ≈ 删除

用户感知层面「取消」等同于「删除」：已取消的目标默认从视图中隐藏，如同被删除。但逻辑层保留完整记录。传达理念：目标要认真对待。

### 0.2 空槽位 = 提醒

空槽位边（taskNodeRef 为空）在视觉上以「待定义」样式提醒用户：要达成目标需要具体的行动计划。

### 0.3 状态只读

目标的状态由逻辑层推导（C8），用户不能手动标记目标完成。任务边的状态派生自关联任务，UI 层不直接修改边状态。

### 0.4 AND/OR 是简化入口

UI 层提供 AND/OR 切换作为 completionRule 的简化操作入口。底层 DNF 的完整编辑能力留给后续版本。

## 1. 视图架构

### 1.1 主视图：目标网络（力导向图）

画布式力导向图，是目标系统的主交互界面：

- **节点**：Me（固定中心）+ 目标节点（外围）
- **边**：任务边（有向，箭头指向 target）
- **布局**：d3-force 物理模拟

### 1.2 辅助面板：详情面板

点击节点或边后弹出的侧边/底部面板，展示和编辑属性。

### 1.3 已取消目标的隐藏与恢复

- 已取消的目标节点（及其关联边）**默认隐藏**
- 提供「显示已取消」开关，切换显示/隐藏
- 隐藏时，从 cancelled 目标出发的僵尸边也一并隐藏

### 1.4 未来视图：星图视图

概念视图，本版本不实现，仅保留设计意向。

## 2. 力导向布局

### 2.1 物理模拟参数

| 力 | 作用 | 说明 |
|----|------|------|
| 排斥力 | 目标节点间相互排斥 | 防止重叠 |
| 链接约束 | 任务边约束两端距离 | 连接的节点不会飞太远 |
| 中心力 | Me 固定在画布中心 | Me 坐标 (0, 0)，不参与物理模拟 |

### 2.2 距离语义（视觉呈现）

逻辑层提供 `getHopDistance(goalId)` → UI 层用此值：

- 渲染距离标尺（同心圆或径向刻度）
- 近（1跳）= 近期目标，远（多跳）= 长期目标
- 标尺方向：Me 向外，越远越长期
- 注：路径计算排除 cancelled 边

### 2.3 节点视觉

| 节点类型 | 外观 | 状态映射 |
|----------|------|---------|
| Me | 特殊样式（大圆、高亮） | 始终显示 |
| 目标-pending | 默认样式 | 可交互 |
| 目标-in_progress | 默认样式 + 进行中指示器 | **派生**：有入边在 in_progress |
| 目标-suspended | 默认样式 + 挂起指示器 | **派生**：有入边 suspended 或所有入边已终结但规则未满足 |
| 目标-completed | 完成样式（绿色/打勾） | 吸纳动画后淡化 |
| 目标-cancelled | 默认隐藏 | 「显示已取消」开关打开时半透明展示 |

> suspended 有两种子情况：(a) 有任务被暂停；(b) 所有手段用尽等待新手段。UI 可通过 tooltip 区分。

### 2.4 边视觉

| 边状态 | 外观 | 说明 |
|--------|------|------|
| pending（空槽位） | 细虚线 + 「待定义」标签 | 提醒用户绑定任务 |
| pending（有任务） | 虚线 | 任务尚未开始 |
| in_progress | 实线 + 高亮色 | 正在进行 |
| suspended | 虚线 + 暗色 | 已挂起 |
| completed | 实线 + 完成色 | 已完成 |
| cancelled | 极淡/半透明 | 已取消（随 cancelled 目标隐藏） |

## 3. 用户操作 → 逻辑 API 映射

### 3.1 添加目标（基于节点派生）

| 交互 | 逻辑调用 |
|------|---------|
| 右键目标节点 → 添加下游目标 | `createGoal({ fromNode: goalId, direction: 'downstream' })` → 弹出命名输入框 |
| 右键目标节点 → 添加上游目标 | `createGoal({ fromNode: goalId, direction: 'upstream', rulePosition: { clauseIndex: 0 } })` → 弹出命名输入框 |
| 右键 Me → 添加目标 | `createGoal({ fromNode: meId, direction: 'downstream' })` → 弹出命名输入框 |

> 目标不能凭空创建（C5），必须基于已有节点派生。Me 上只能 downstream。

### 3.2 添加任务边（连线）

| 交互 | 逻辑调用 |
|------|---------|
| 从节点 A 拖拽到节点 B | `createEdge({ source: A.id, target: B.id, rulePosition: { clauseIndex: 0 } })` |

**rulePosition 的 UI 决策**：
- 默认 AND 模式（clauseIndex: 0，加入第一个子集）
- 后续可提供弹窗让用户选择加入方式（AND 合并 vs OR 独立）

**失败处理**：
- DAG 检测失败 → toast 提示「不能形成环」，取消操作
- 自环 → toast 提示「不能连到自己」
- target 为 completed → toast 提示「已完成的目标不能添加新任务」
- source 为 cancelled → toast 提示「已取消的目标不能发起新任务」

### 3.3 编辑属性

| 交互 | 逻辑调用 | 冻结规则 |
|------|---------|---------|
| 详情面板修改目标标题 | `updateGoal({ goalId, title })` | 终态目标不可编辑 |
| 详情面板修改目标描述 | `updateGoal({ goalId, description })` | 终态目标不可编辑 |
| 详情面板切换 AND/OR | 见 §3.8 | 终态目标不可编辑 |
| 详情面板修改边标题 | `updateEdge({ edgeId, title })` | completed target 的入边不可编辑 |
| 详情面板绑定/解绑任务 | `updateEdge({ edgeId, taskNodeRef })` | completed target 的入边不可编辑 |

### 3.4 取消目标

| 交互 | 逻辑调用 |
|------|---------|
| 右键菜单 → 取消目标 | 弹窗确认，含两个可选勾选框 → `cancelGoal({ goalId, cascadeInTasks, cascadeOutTasks })` |

**弹窗内容**：
```
确认取消目标「xxx」？
☐ 同时取消入边关联的任务（达成手段）
☐ 同时取消出边关联的任务（后续路径）
        [取消]  [确认]
```

取消后目标从视图中隐藏（§1.3）。

### 3.5 删除任务边

| 交互 | 逻辑调用 |
|------|---------|
| 右键边 → 删除 | `deleteEdge({ edgeId })` |

**失败处理**：
- target 为 completed → toast 提示「已完成目标的入边不可删除」

### 3.6 拆解边

| 交互 | 逻辑调用 |
|------|---------|
| 右键边 → 拆解 | 弹窗 → `splitEdge({ edgeId, ... })` |

**拆解弹窗**：
1. 选择中间节点：「新建目标」（输入名称）或「选择已有目标」（下拉列表）
2. 原边分配：「原边作为前半段」或「原边作为后半段」
3. 确认 → 调用 splitEdge

失败时（如 DAG 检测）整体回滚，toast 提示原因。

### 3.7 修改边的端点（reconnect）

| 交互 | 逻辑调用 |
|------|---------|
| 拖拽边的端点到新节点 | `reconnectEdge({ edgeId, newSource/newTarget, rulePosition })` |

**失败处理**：同 §3.2。

### 3.8 AND/OR 切换（completionRule 简化入口）

| 交互 | 逻辑调用 |
|------|---------|
| 详情面板切换为 AND | `updateGoal({ goalId, completionRule: [[所有入边ID]] })` |
| 详情面板切换为 OR | `updateGoal({ goalId, completionRule: 入边ID.map(id => [id]) })` |

AND → 逻辑层设为 `{ {所有入边} }`（一个子集含全部入边）
OR → 逻辑层设为 `{ {E1}, {E2}, ... }`（每条入边一个独立子集）

**展示**：根据当前 completionRule 结构反推显示 AND/OR/自定义。

### 3.9 画布操作

| 交互 | 说明 |
|------|------|
| 拖拽节点 | 改变物理模拟位置，松手后继续模拟 |
| 缩放 | 鼠标滚轮 / 双指缩放 |
| 平移 | 拖拽画布空白 |

## 5. 视觉特效

### 5.1 吸纳动画（P1）

当目标达成推导为 completed 时，触发「吸收」动画——目标被 Me 吸纳：

1. **聚拢**：目标节点脱离力导向布局，沿直线向 Me 中心移动（~500ms，ease-out）
2. **缩小**：移动过程中节点逐渐缩小至 Me 圆的边缘（scale 1.0 → 0.2）
3. **融合**：节点到达 Me 边缘时淡出消失（opacity 1.0 → 0）
4. **Me 脉冲**：Me 圆短暂扩大+发光脉冲（~300ms），表示「吸收完成」
5. **归位**：动画结束后，目标节点切换为 completed 样式，回到原始拓扑位置淡入显示（opacity 0 → 0.3），保留在图中但视觉降级

**关联边的动画**：
- 目标的入边在聚拢阶段跟随缩短，融合时淡出
- 动画结束后入边恢复显示（completed 样式：实线绿）

**语义**：完成目标 = 目标归于自身 = 被 Me 吸收。这不是「消失」而是「成为我的一部分」。

### 5.2 级联传播高亮（P1）

达成推导沿 DAG 传播时，沿传播路径的边短暂高亮闪烁（~300ms），帮助用户理解「为什么这个目标突然完成了」。

### 5.3 待命名/待定义提示

- 目标 title 为空 → 显示半透明「待命名」，点击进入编辑
- 空槽位边 → 显示半透明「待定义」，点击打开详情面板引导绑定任务

## 6. 右键菜单

### 6.1 目标节点右键

| 菜单项 | 可用条件 | 动作 |
|--------|---------|------|
| 编辑 | 非终态 | 打开详情面板 |
| 添加下游目标 | 非 cancelled | createGoal downstream |
| 添加上游目标 | 非 cancelled 且非 Me | createGoal upstream |
| 连接到... | 非 cancelled | 进入连线模式 |
| 取消目标 | status = pending（含派生 in_progress/suspended） | 弹窗确认 → cancelGoal |

> completed 目标只显示「查看详情」（只读）。cancelled 目标默认隐藏，不出现右键菜单。

### 6.2 任务边右键

| 菜单项 | 可用条件 | 动作 |
|--------|---------|------|
| 编辑 | target 非 completed | 打开详情面板 |
| 拆解 | target 非 completed | 弹窗 → splitEdge |
| 删除 | target 非 completed | deleteEdge |
| 查看详情 | 总是 | 打开详情面板（只读） |

> 不再提供「标记完成」和「取消」菜单项——边的状态由关联任务决定（§0.3）。

### 6.3 Me 节点右键

| 菜单项 | 动作 |
|--------|------|
| 编辑名称 | 修改 Me.name |
| 添加目标 | createGoal({ fromNode: meId, direction: 'downstream' }) |

## 9. 与逻辑模型的接口映射总览

| UI 操作 | 逻辑 API | rulePosition 策略 |
|---------|---------|-------------------|
| 添加下游目标 | createGoal(downstream) | 新目标自动 AND |
| 添加上游目标 | createGoal(upstream, rulePosition) | 默认 clauseIndex=0 |
| 拖拽连线 | createEdge(rulePosition) | 默认 clauseIndex=0（AND 合并） |
| 切换 AND | updateGoal(completionRule: [[全部入边]]) | — |
| 切换 OR | updateGoal(completionRule: 入边.map(e=>[e])) | — |
| 取消目标 | cancelGoal(cascadeInTasks, cascadeOutTasks) | — |
| 删除边 | deleteEdge | — |
| 拆解边 | splitEdge | — |
| 修改端点 | reconnectEdge(rulePosition) | 必填 |
| 绑定任务 | updateEdge(taskNodeRef) | — |

## 10. 与 v0.2 的差异

| 变化点 | v0.2 | v0.3-ui |
|--------|------|---------|
| 文档范围 | 逻辑+UI 混合 | 纯 UI 交互 |
| 添加目标 | 点击空白处 | 基于节点派生（右键菜单） |
| 目标状态 | 3 种 | 5 种（含派生 in_progress/suspended） |
| 边状态编辑 | 直接改 | 不可直接改（派生自任务） |
| 取消联动 | 弹窗单选 | 弹窗双勾选（入边/出边分别可选） |
| completionRule | AND/OR 切换 | AND/OR 作为 DNF 简化入口 |
| 已取消目标 | 半透明展示 | 默认隐藏 + 显示开关 |
| rulePosition | 无 | 每个创建/reconnect 操作必须指定 |
| 空槽位 | 「待命名」 | 「待定义」+ 引导绑定任务 |
| 终态冻结 | 部分 | 完全冻结（所有字段不可编辑） |
