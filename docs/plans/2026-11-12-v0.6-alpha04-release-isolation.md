## 4. 本轮 CI 修复

为让完整 release CI 达到可审计的绿色状态，本轮做了三项最小修复：

1. Android 生成包名已变为 `com.exomind.app.v06`，补丁脚本与 CI 校验改为递归解析生成的 `MainActivity.kt`，不再硬编码旧路径。
2. Windows AppBar/action-dock 的桌面 API 在 Android 上不可用；新增移动端 no-op/error stub，并用条件编译隔离桌面实现。
3. Tauri 日志插件原先固定写默认 LocalAppData；显式 AppData root 现在同时拥有日志目录，支持 `EXOMIND_DEV_LOG_DIR` 优先覆盖。
